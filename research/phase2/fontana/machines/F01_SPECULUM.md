# F01 — Speculum

## Source evidence

[ИСТОЧНИК] NAL 635, 19v–21r: концентрические круги на одной плоскости вращаются вокруг центра; круги делятся общими радиусами, каждый несёт полный алфавит. Буквы слова распределяются по кругам и совмещаются на одном полудиаметре. Рисунок — 21r. Транскрипция: Battisti/Saccaro 1984, 145.

## Physical/conceptual structure

[ВЫВОД] Плоский пакет независимо вращаемых колец с общей осью. Минимальная реконструкция не нуждается в зеркальной поверхности: *speculum* — имя прибора.

## Formal representation

`F01 = (Inputs, ExternalState, InternalHumanKnowledge, Operations, Output, RetrievalProcedure)`

- Input: слово `w`, `1 <= |w| <= n`.
- ExternalState: угловое смещение каждого из `n` колец.
- InternalHumanKnowledge: алфавит, длина слова, радиус считывания.
- Operations: `rotate(i, offset)`, `align(w[i], radius)`, `read(radius)`.
- Output: буквенная последовательность на радиусе.
- Retrieval: прочитать кольца в фиксированном порядке снаружи внутрь либо наоборот — порядок должен быть заранее закреплён.

## Construction procedure

[ИСТОЧНИК] Разделить круги равными радиальными линиями; на каждом кольце поместить полный алфавит, по одной букве в секторе. [ВЫВОД] Для работоспособной модели нужны ось, раздельное вращение, достаточное трение и отметка рабочего радиуса.

## Retrieval procedure

[ИСТОЧНИК] Поворачивать круги раздельно, пока буквы слова не окажутся на одном полудиаметре. [ВЫВОД] При повторном чтении состояние непосредственно возвращает буквы, но не значение или контекст.

## Ambiguities and errors

- [ИСТОЧНИК] направление порядка колец в приведённом фрагменте не уточнено.
- [ВЫВОД] неверный поворот одного кольца даёт локальную замену одной буквы; потеря состояния уничтожает сохранённый cue.
- [ВЫВОД] без знания длины возможны лишние буквы с неиспользованных колец.
- [СПЕКУЛЯЦИЯ] использование относительных смещений как полиалфавитного шифра технически возможно, но не требуется данной инструкцией запоминания.

## Reconstruction confidence

**HIGH** для мнемонической фиксации букв; **MEDIUM** для криптографических расширений.
