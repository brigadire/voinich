# Knowledge-dependent / information-reducing notation taxonomy

| Class | Operational representation | Historical/control status |
|---|---|---|
| A. Shorthand / tachygraphy | Signs compress phrases or words using memorised rules. | Tironian running-text aligned control not found. |
| B. Scribal abbreviation | Suspension, contraction and conventional signs omit characters. | Aligned Burchard/Abbreviationes candidate; CATMuS/CoMMA unaligned controls. |
| C. Notae / sigla | Conventional signs stand for names, words or formulae. | Cappelli is a reference lexicon, not a frequency corpus. |
| D. Mnemonic cues | Marked cues require shared associations to reconstruct content. | No suitable aligned corpus found. |
| E. Positional extraction | A fixed position carries a second channel. | Fixed line/token/glyph channels tested below. |
| F. Acrostic / telestich | Line-initial or line-final positions form a channel. | A restricted statistical test is possible; no message inference is licensed. |
| G. Grille / periodic selection | A rule selects fragments or positions. | Rugg/Zandbergen are quantitative proof-of-concept studies. |
| H. Omission / contextual completion | Context supplies omitted material. | Needs aligned source/notation data; unavailable here. |
| I. Mixed systems | Any combination of the preceding mechanisms. | Treat as separate future experimental families. |
| J. Other | Any system with `M,K -> X` but no unique `X -> M`. | Must meet the same pre-registration and control requirements. |
