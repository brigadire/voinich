# C08 — Positional numerical notation

Require real structured historical measurements, accounting, or astronomical
records; random numbers cannot be the sole production corpus. Preserve record,
field/column, unit, sign, decimal/sexagesimal convention, physical row, and
page. NUMERIC-RECORD tokens are source fields and symbols are the written
digits/signs. Dimensionality is linear inside fields and tabular/hierarchical
across records. Production source selection remains blocked.
