# C07 — Historical tablature

Acquire scholarly TabCode/full-text lute encodings separately for French,
Italian, and German traditions. TAB-R1 tokens are simultaneity/chord groups;
ordered symbols are course–fret components. TAB-R2 tokens are course events
but retain the same simultaneity ID. Preserve rhythmic sign, course/string,
fret, sequence order, source system, and tradition.

Dimensionality: two-dimensional, simultaneous, course-position dependent,
system-structured, and hierarchical. Physical system is a line only when
encoded. This prevents silent loss of simultaneity or conversion of courses
into a false character stream.
