# C09 — Formal/tabular notation

Require a scholarly transcription of historical astronomical, calendrical,
mathematical, or accounting tables where layout is information-bearing.
TABLE-CELL tokens are non-empty cells; row/column and header/body roles remain
attributes. Rows/pages are observed levels only when present in the source.
Dimensionality is tabular, two-dimensional, and hierarchical. Production
source selection remains blocked.
