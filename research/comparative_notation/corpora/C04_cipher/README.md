# C04 — Historical cipher

Acquire DECODE records as separate corpus instances for monoalphabetic,
homophonic, and nomenclator mechanisms. Never pool mechanisms, keys, or
cipher alphabets. Preserve diplomatic sign groups, lines/pages if present,
metadata, key identity, and plaintext alignment. Linear/line-structured with
document hierarchy as source-observed; nomenclator codebook structure is an
attribute, not an invented text hierarchy.
