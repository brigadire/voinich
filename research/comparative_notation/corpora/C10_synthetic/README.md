# C10 — Synthetic grammar controls

Calibration suite: IID, first-order Markov, second-order Markov, C-GRAMMAR,
token-frequency preserving shuffle, and line-preserving shuffle. Every
generator/transform has a frozen parameter file, seed 20260830, and provenance;
all use SYNTHETIC-TOKEN USC and the same analyzer. These are calibration
controls, never historical candidates. Declared lines/pages belong to the
generator and are not inferred from VM.
