# C07 licensing review — ECOLM / TabCode corpus

Review date: 2026-08-30. License decision: `LICENSE_UNRESOLVED`.
First-run decision: `EXCLUDED_LICENSE`; `C07_PRODUCTION_READY=false`.

The ECOLM site documents Basic and Full TabCode and describes French, Italian,
and German traditions, but the reviewed corpus and TabCode pages show a
Goldsmiths copyright notice and no license granting bulk download, local
corpus storage, normalization, creation/redistribution of derived USC, or
redistribution of the encoded works.

| Use | Result |
|---|---|
| Browse/search public site | Available. |
| Download complete source encodings | No stable versioned bulk release identified. |
| Local storage / machine analysis | No explicit permission identified for corpus content. |
| Derived USC creation or redistribution | Not licensed by the reviewed pages. |
| Derived aggregate statistics | Not enough to cure the missing acquisition/analysis permission. |
| Excerpts | Requires source-specific review; not assumed. |

The open availability or documentation of TabCode is not a license for the
encoded corpus. The separate `luteconv` software license also does not grant
rights to ECOLM data. Written permission or a versioned corpus release with
explicit terms is required before acquisition.

Sources checked: `https://igor.gold.ac.uk/isms/ecolm/?page=TabCode` and linked
ECOLM pages (accessed 2026-08-30).
