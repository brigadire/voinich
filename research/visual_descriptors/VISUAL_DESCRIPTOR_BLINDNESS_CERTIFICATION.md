# Visual descriptor blindness certification

Status: certified for the frozen 1.0.0 annotation layer.

The descriptor vocabulary was selected and frozen before the final page table was assembled. The predeclared audit sample contains 46 page IDs; its independent pass is retained as `VISUAL_DESCRIPTOR_FULL_AUDIT_PASS.tsv`. The final table contains all 227 neutral annotation units and uses only the frozen 15 visual descriptors.

Clean-room pass manifests attest that annotators received only the frozen schema/protocol, neutral page identification, image locators, panel registry/crops, and predeclared IDs. No Currier, hand, quire, token, line, section, fingerprint, or other textual-analysis outputs were provided. The earlier contaminated pilot is retained for audit history and is not used in the final table, reliability, or adjudication.

`TEXTUAL_ASSOCIATION_ANALYSIS_PERFORMED=false` and `TEXTUAL_RESULTS_USED_FOR_DESCRIPTOR_SELECTION=false` are enforced in the results manifest and validator.
