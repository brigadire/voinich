# Global mapping propagation

The amended DFS carries a single injective `source -> output` map. Before a branch is extended, it checks mapping conflicts and reverse-map conflicts. After extension it replays every already selected path and the candidate through the full scorer. A branch is discarded immediately if any selected output changes or gains extra characters. A final independent replay remains mandatory.
