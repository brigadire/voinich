# Support feasibility result

A complete enumeration of 793870 local mapping variants found a consistent witness with 2 one-to-one correspondence edges and a 4-rule global table. The two EVA tokens are `olchc` and `chol`; each of the four used rules therefore has support from both distinct EVA token types. The witness satisfies GLOBAL_CAPACITY_1 and table size <=5. This is an existential model-feasibility result, not a coverage optimum or scientific claim.
