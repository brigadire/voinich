# Remediation report

The generator now treats mapping as a function of source-unit type. The first decision for a source unit is globally recorded as mapped or unmapped; later occurrences cannot change it. Position-wise subsequence alignment enumeration has been removed.

The exact DFS passed exhaustive small-string agreement. With the frozen five-mapping E2 contract, the new identity/no-operation generator has exact set equivalence: 25,469 signatures, zero missing, zero extra. Three regenerated E3 smoke profiles were persisted with checksums and replay audits. Their measured generation costs project a sequential full 64-profile run as resource-feasible, so `E3_FULL_RUN_READY=YES`. The full run itself was not launched.
