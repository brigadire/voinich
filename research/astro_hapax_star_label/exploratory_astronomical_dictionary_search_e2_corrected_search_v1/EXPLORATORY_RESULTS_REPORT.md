# Corrected E2 exploratory search

The corrected search sampled tables with one through five injective rules. Support was evaluated only for rules actually used by the final one-to-one assignment; unused table rules were not counted as violations.

Three deterministic seeds ran for equal 30-second budgets. Maximum raw coverage was 3/57. No support-valid incumbent was found. The best raw tables had 2–3 distinct EVA token types but every used rule was a singleton, so support-valid coverage was 0/57.

This is not an exact negative result. The search is heuristic and the absence of a valid incumbent does not show that no table of size at most five exists.
