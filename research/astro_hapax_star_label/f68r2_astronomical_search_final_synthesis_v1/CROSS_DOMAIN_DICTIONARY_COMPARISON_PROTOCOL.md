# Cross-domain dictionary comparison protocol

This is a protocol only. No botanical or control search is run by this package.

The already completed astronomical search is one prespecified domain. A future comparison must freeze, before inspecting new results, a botanical dictionary and a matched general proper-name or pseudodictionary control. Each dictionary must have comparable row count, token-length distribution, character alphabet/composition, and canonical-identity handling. Any deviations must be reported before search.

The future runs must use the same 64 frozen operation profiles, corrected global scorer, GLOBAL_CAPACITY_1, DROP_UNMAPPED semantics, distinct-EVA support gate, profile-selection scope, deterministic seed plan, and per-profile search budget. The primary metric must be fixed in advance as the maximum support-valid occurrence coverage, with complexity recorded as a secondary tie-breaker. The full model-selection pipeline must be repeated for every domain, including selection over profiles and complexity.

The analysis must compare astronomical, botanical, and matched-control maxima with an adjustment for comparing multiple thematic dictionaries. The adjustment method and its estimand must be preregistered before any botanical result is inspected. A domain cannot be selected post hoc because it produced the larger maximum. Any claim must be framed as relative performance under the same model and controls, not as identification of labels.
