POLICY

RIGHTS

Licensing and reuse boundary

The included Apache-2.0 file covers original project code under the repository’s declared scope. It does not silently license third-party corpora, manuscript images, IVTT, or all scientific documentation. Documentation rights remain scope-undetermined where the release audit says so. Consult the original authorities and artifact records before redistribution.

No manuscript facsimile image is redistributed on this site. The abstract line drawing is an original decorative site asset and is not scientific evidence.
