# Future model families

The current global-substitution branch is closed. A future experiment requires independent historical or linguistic justification before any run and must be preregistered before coverage is inspected.

## Abbreviational

Use documented historical abbreviation conventions, with a frozen expansion inventory, positional rules, complexity penalties and held-out validation. Controls must use the same historical mechanism.

## Mnemonic or notational

Test a documented catalogue, memory aid or diagrammatic notation with fixed mapping rules and an independent source tradition. Free-form semantic association is not evidence.

## Morpheme-compositional

Test reusable subunits and a fixed composition grammar only when independently supported. Freeze segmentation, inventory, penalties and repetition-preserving nulls; evaluate held-out forms.

These are new model classes, not parameter tuning of the failed global substitution. No future model is authorized by this publication.
