Frozen conclusion map

From resemblance to mechanism.

Phase II did not begin as an independent attribution argument about Fontana. It formalized a question created by Phase I: when surface statistics do not identify recovery or information behavior, can external-state mechanism classes be tested directly?

Reading rule. The map below is condensed from the frozen PHASE1_TO_PHASE2_CONCLUSION_MAP.tsv. “Confirmed” means the scoped Phase I relationship survived the Phase II test; it does not confirm a Voynich generating mechanism.

CHAIN

The logical handoff

P1P2-01 · CONFIRMED

Strongly constrained token formation

Phase I: constrained formation was central in the tested grid. Phase II: Fingerprint V2 preserved edit/token CORE structure across ZL3b and IT2a. Open: the generating cause remains unidentified.

P1P2-02 · REFINED

Edit neighborhoods are real; “paradigms” remain bounded

Task77 reproduced a large edit-rule network, but its aggregate concentration did not exceed the position/bigram-matched C-GRAMMAR null. Formal edit structure is not demonstrated lexical morphology.

P1P2-03 · CONFIRMED

Input dependence is measurable

Phase II measured input-sensitive and input-insensitive synthetic cells across corpora and scales. Input dependence does not imply autonomous decoding or a Voynich plaintext.

P1P2-04 · CONFIRMED

Surface proximity and information behavior are separate

External state, convention, path, context, association, collision and recovery were operationalized. Endpoint proximity still yielded no supported class.

P1P2-06 · CONFIRMED

Knowledge-assisted recovery can differ from autonomous recovery

Wrong-knowledge controls and ablations quantified specificity for tested synthetic mechanisms. This was not demonstrated for the Voynich Manuscript.

CAUSAL BRIDGE · EXTERNAL MEMORY

Why external memory was considered

Phase I showed that surface organization and recoverability cannot be inferred from one another. This left open a class of systems in which the visible record is not intended to carry all information autonomously: successful use may depend on an external convention, remembered association, reading path, index, state, or contextual knowledge. Phase II called this property external memory and converted it into measurable variables.

HISTORICAL MODEL SOURCE · FONTANA

Why Fontana was used

Giovanni Fontana’s Secretum, produced in approximately the same historical period as the Voynich Manuscript, describes concrete systems involving symbolic cues, conventions, ordered paths, indices, associations, and information retained outside the visible record. This allowed historically grounded, computationally testable mechanism families to be derived instead of inventing an arbitrary modern “mnemonic” model.

Fontana was used as a source of bounded experimental mechanisms, not as a proposed author or demonstrated influence on the Voynich Manuscript. The experiment asks whether outputs of Fontana-derived mechanism models reproduce selected properties of the Voynich fingerprint—not whether the Voynich Manuscript “looks like” the Secretum.

P1P2-07 · REFINED

External memory became a testable model property

Fontana-derived models operationalized convention, path, index and association dependence. Their Voynich compatibility stopped at LEVEL_1.

P1P2-08 · UNCHANGED

Narrow cipher negatives stayed narrow

Phase II did not repeat or broaden the simple inverse-transposition and random-homophony tests. No global verdict on cipher follows.

P1P2-09/10 · UNCHANGED / NOT_TESTED

Natural/formal language and message-free generation stayed open

Natural text was descriptively closest but only partial. Formal grammar and semantic absence were not directly adjudicated.

P1P2-12 · CONFIRMED

The broad classes remain unidentified

Only 3 of 13 CORE metrics were directly shared with models, all in one family. The exact terminal result is INCONCLUSIVE / NOT_IDENTIFIABLE.
