Task85c-f — G1-v2 Nonempty Token Generation Semantics,
RNG Consumption Resolution and Scientific Contract V1.2 Refreeze


PURPOSE

Resolve the genuine scientific-contract defect:

    PF-SC01-EMPTY-TOKEN-GENERATION

discovered during:

    Task86C-v2-production-freeze.

The frozen G1-v2 V1.1 protocol requires generated tokens to be
nonempty, but at least one reachable frozen generation path permits
<EOS> to be selected before any glyph has been emitted.

For the frozen M0_GEN_A case:

    DRAW0_U53     = 0.92848667210989588
    DRAW0_OUTCOME = <EOS>

At least two reasonable implementations produce different
deterministic corpora:

    retry / consume next RNG draw
        → first glyph = a

    conditional renormalization
        → first glyph = d.

Because generated DEVELOPMENT controls determine calibration and
thresholds, this ambiguity can propagate to scientific verdicts.

Therefore PF-SC01 is a SCIENTIFIC_CONTRACT_DEFECT.

Task85c-f must:

    reproduce PF-SC01;
    audit the complete frozen generation apparatus for the same
    defect class;
    define mathematically explicit nonempty-generation semantics;
    define exact RNG-consumption semantics;
    produce boundary golden vectors;
    demonstrate that every affected generation path is uniquely
    reproducible;
    issue a narrowly revised scientific contract V1.2.

This is a scientific-contract repair.

It is NOT production execution.

======================================================================
12. PREFERRED FORM OF RESOLUTION
======================================================================

Where a symbol is structurally impossible in the current generation
state, define the sampling distribution over the set of currently
admissible outcomes.

Conceptually:

    A(s) = set of admissible outcomes in generation state s

    P_s(x) =
        P(x) / Σ[y ∈ A(s)] P(y),   x ∈ A(s).

Then consume exactly one frozen categorical RNG draw from P_s.

This provides:

    an explicit conditional probability law;
    one RNG draw per categorical decision;
    no hidden rejection-loop consumption.

HOWEVER:

This is a proposed methodological resolution, not permission to
override a contradictory higher-precedence frozen model definition.

The task must verify that this interpretation is compatible with
the intended M0–M5 probability semantics.

If not:

    STOP SCIENTIFIC_CONTRACT_DEFECT_EXPANDED.
