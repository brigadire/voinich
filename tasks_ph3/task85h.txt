Task85c-h — G1-v2 V1.2 Production Scientific Implementation,
Handler Closure and Pre-Materialization Validation


PURPOSE

Implement and independently validate the complete production
scientific execution layer required by:

    G1_V2_EXECUTABLE_CONTRACT_V1_2

without materializing any production controls, thresholds, escrow,
JobIDs, DAG, or confirmatory results.

Task86C-v2-production-freeze reached its mandatory
pre-materialization gate and stopped with:

    IMPLEMENTATION_VALIDATION_FAILURE

because the current:

    cmd/g1v2-executor

and:

    internal/g1v2

implement execution/evidence transport but do not implement the
complete frozen scientific protocol.

The current executor explicitly lacks production scientific
implementations for at least:

    corpus scientific processing;
    fitting;
    M0–M5;
    generation;
    predictive metrics;
    F2 metrics;
    scientific gates;
    scientific aggregation.

Its stage model and JobID implementation also predate the frozen
V1.2 + E1 execution contract.

Task85c-h must close this implementation gap.

It MUST NOT make new scientific choices.

Success means:

    every scientific operation required for production execution
    has an implementation traceable to frozen V1.2;

    every production handler is independently validated;

    the production executor uses the frozen V1.2 stage and JobID
    semantics;

    bounded non-confirmatory end-to-end execution succeeds;

    Task86C-v2-production-freeze can be restarted from its
    pre-materialization gate.

Success does NOT mean:

    production controls have been created;
    thresholds have been calibrated;
    production executable has been finally frozen;
    capacity has been finally qualified;
    production DAG has been materialized;
    production execution has started.
