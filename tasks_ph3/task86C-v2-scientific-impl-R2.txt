136. STOP CONDITIONS
======================================================================

STOP:

    CONTRACT_IDENTITY_FAILURE

if V1.1 or required parent identities fail.

STOP:

    CONTRACT_DEFECT

if V1.1 remains scientifically ambiguous or internally
contradictory.

STOP:

    GOLDEN_CONTRACT_CONTRADICTION

if frozen V1.1 normative semantics and golden expected output cannot
both hold.

STOP:

    INPUT_PROVENANCE_FAILURE

if required immutable source/input identity cannot be reproduced.

STOP:

    BLINDNESS_VIOLATION

if blind truth leaks into unauthorized artifacts or execution.

STOP:

    DAG_CONSTRUCTION_FAILURE

if exact DAG cardinality/identity cannot be reproduced.

STOP:

    EVIDENCE_CONTRACT_FAILURE

if production evidence cannot satisfy/reconstruct the V1.1 evidence
contract.

STOP:

    DETERMINISM_FAILURE

if scientifically identical executions can produce different
scientific evidence.

STOP:

    SCIENTIFIC_FIREWALL_VIOLATION

if blind/natural/Voynich/full-production scientific execution occurs
outside the authorized boundary.

These are mandatory STOP conditions.


======================================================================
137. NON-STOP SCIENTIFIC OUTCOMES
======================================================================

Do NOT stop implementation merely because an authorized scientific
procedure can legitimately produce:

    FIT_FAILURE
    NUMERICAL_FAILURE
    INDUCTION_CAP
    GENERATION_FAILURE
    NOT_ASSESSABLE
    NOT_REACHED
    PROTOCOL_VETO.

Those are part of the frozen state machine.

They must be implemented and tested.

======================================================================
145. DEFINITION OF DONE
======================================================================

Task86C-v2-scientific-impl-R2 is complete when:

A production operator can start the frozen G1-v2 experiment using
only the R2 handoff/runbook and operational resource choices.

The operator cannot alter:

    scientific inputs;
    candidates;
    models;
    RNG;
    thresholds;
    DAG;
    reachability;
    evidence semantics;
    aggregation;
    scientific retry behavior.

Two scientifically identical runs using the frozen artifacts produce
identical scientific evidence regardless of:

    worker assignment;
    scheduling order;
    retry;
    coordinator restart;
    supported operational concurrency.

At that point:

    Task86C-v2-run

is authorized.

No additional scientific design task is permitted between successful
R2 freeze and the production run unless R2 discovers a new mandatory
contract defect.
