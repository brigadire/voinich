    G1_V2_EXECUTABLE_CONTRACT_V1

Task86C-v2 distributed/evidence infrastructure, construct all
authorized immutable execution inputs, validate implementation

and freeze the production scientific executable and authoritative
Task86C-v2 run manifest.

resolution performed by Task85c.

    INTEGRATION
    VALIDATION
    CAPACITY QUALIFICATION
    PRODUCTION FREEZE

This is NOT:

    scientific redesign;
    threshold tuning;
    model-family redesign;
    confirmatory analysis;
    Task86C-v2 bulk execution;
    unblinding;
    Voynich evaluation.

4. IMPLEMENTATION AUTHORITY
======================================================================

The implementation agent is NOT authorized to make scientific
choices.

If the contract specifies algorithm X:

    implement X.

Do not replace it with Y because Y is:

    simpler;
    faster;
    available in a library;
    numerically more familiar;
    scientifically preferable;
    easier to distribute.

Performance problems are capacity problems, not authorization for
scientific modification.
