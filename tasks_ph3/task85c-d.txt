Task85c-d — G1-v2 V1.1 JobID Scientific Identity
and Golden Vector Reconciliation


PURPOSE

Resolve the mandatory STOP discovered by:

    Task86C-v2-scientific-impl-R2

where the frozen G1-v2 V1.1 JobID contract and the frozen JobID
golden vector produce scientifically different JobIDs.

Known blocking findings:

    R2-G01
        golden JobID payload uses contract version V1
        instead of V1.1.

    R2-G02
        golden JobID payload uses "dependencies"
        while the frozen DAG registry uses
        "dependency_job_ids".

Observed consequence:

    three distinct JobIDs are reproducible for what is intended
    to be one scientific job identity.

Task85c-d must determine and freeze ONE authoritative JobID
scientific identity representation, reconcile every transitive
artifact that depends on it, and issue a controlled patch-level
contract refreeze if and only if this can be done without changing
the scientific design.

This task is:

    CONTRACT DEFECT RESOLUTION
    JOBID IDENTITY RECONCILIATION
    GOLDEN VECTOR RECONCILIATION
    TRANSITIVE IDENTITY AUDIT
    CONTROLLED PATCH REFREEZE

It is NOT:

    scientific redesign;
    model redesign;
    RNG redesign;
    DAG redesign;
    status/reachability redesign;
    evidence semantics redesign;
    production implementation;
    threshold computation;
    blind-control construction;
    production execution;
    Voynich evaluation.
