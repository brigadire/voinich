Task86C-v2-scientific-impl
G1-v2 Scientific Workload Implementation, Manifest Construction
and Production Execution Freeze


PURPOSE

Implement the frozen G1-v2 scientific workload required for
Task86C-v2 blind control validation and produce the exact immutable
artifacts required for operator execution.

This task bridges:

    Task85b
        frozen scientific experiment contract

and:

    Task86C-v2-prep
        frozen distributed/evidence infrastructure

to produce:

    production scientific executable
    authoritative Task86C-v2 run manifest
    immutable input closure
    executable evidence-only verification path

required by:

    Task86C-v2-run.

This task is IMPLEMENTATION + VALIDATION + FREEZE.

It is NOT:

    a redesign of G1-v2;
    a scientific result;
    the Task86C-v2 confirmatory run;
    an analysis of Voynich;
    an opportunity to tune G1-v2 against controls.

    frozen scientific implementation

    frozen input closure

    frozen blind manifest

    frozen distributed executor

    reproducible Task86C-v2 computation.

16. PM6-v2
======================================================================

Implement the frozen constructive finite-complement PM6-v2 protocol.

For token length l:

    C_l = A^l \ V_l

and:

    |C_l| = |A|^l - |V_l|.

Use the exact Task85b protocol.

Sampling is with replacement where frozen.

A saturated length must NOT become:

    TRAINING_FAILED
    NEGATIVE_EXHAUSTED

merely because no complement exists.

Use the frozen three-valued semantics, including:

    NOT_ASSESSABLE

when the negative discrimination question is not identifiable.
