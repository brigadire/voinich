Task85c-g — G1-v2 Complete Generative Semantics Resolution
and Scientific Contract V1.2 Freeze


PURPOSE

Resolve the complete G1-v2 generation-semantics defect class exposed
by Task85c-f and produce one self-contained executable scientific
contract:

    G1_V2_EXECUTABLE_CONTRACT_V1_2.

Task85c-f demonstrated that:

    PF-SC01-EMPTY-TOKEN-GENERATION

is reproducible, but is not an isolated defect.

The generation layer as frozen in V1.1 does not uniquely define the
function:

    frozen model state
        +
    frozen generation parameters
        +
    frozen G1V2-RNG-1 stream
        →
    exact generated token sequence
        →
    exact serialized corpus bytes.

Task85c-f audited 25 generation paths and found 8 open generation
ambiguities, including at least:

    PF-SC01 nonempty-token generation;

    Generator B sampling algorithms;

    canonical outcome enumeration/order;

    token maximum-length semantics;

    M5 attempt/counter/RNG-consumption semantics;

    generated-corpus byte serialization.

Task85c-g must resolve the ENTIRE generation subsystem as one
scientific-contract repair.

It must NOT repair one ambiguity and STOP merely because another
ambiguity of the same generation-semantics class is discovered.

The task must continue until either:

    A. the complete generation subsystem is executable without
       unstated scientific choices and V1.2 can be frozen;

or:

    B. a defect outside the authorized generation-repair scope is
       discovered, or the generation requirements cannot be made
       mutually coherent without redesigning unrelated scientific
       components.

No production experiment is executed by this task.

82. DEFINITION OF DONE
======================================================================

Task85c-g is complete only when the entire G1-v2 generation layer
defines a unique scientific transformation:

    frozen fitted model
        +
    frozen generator identity
        +
    frozen generation parameters/state
        +
    frozen G1V2-RNG-1 stream
        →
    exact logical generated corpus
        →
    exact canonical corpus bytes.

No implementation may need to choose:

    outcome ordering;
    retry vs conditioning;
    number of RNG draws;
    alias construction;
    exponential-race enumeration;
    tie behavior;
    EOS handling;
    maximum-length behavior;
    M5 attempt semantics;
    counter reset semantics;
    corpus delimiters;
    final newline behavior;

or any equivalent scientifically consequential generation detail.

The purpose of Task85c-g is to end the generation-repair chain.

Finding another ambiguity inside generation is work to be completed
inside Task85c-g, not justification for Task85c-h.

Only a genuine out-of-scope scientific contradiction, an
irreconcilable generation design, validation failure, or firewall
violation may prevent the V1.2 freeze.
