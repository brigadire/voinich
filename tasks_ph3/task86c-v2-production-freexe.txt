Task86C-v2-production-freeze —
G1-v2 Production Implementation, Blind Materialization and Run Freeze


PURPOSE

Complete the production implementation and materialization of the
frozen G1-v2 experiment and produce one immutable, executable
production run instance.

This is a new clean run. It is not a continuation of either historical
Task86C-v2 production-freeze attempt.

The task starts from:

    G1_V2_EXECUTABLE_CONTRACT_V1_2_1

together with:

    G1V2_V1_2_1_INTEGRATION_SUPPLEMENT_I2
    G1V2_EXECUTION_IDENTITY_ERRATUM_E3
    G1V2_EVIDENCE_CONTRACT_V1_2_1
    Task85c-h scientific implementation root
        5687f219c049f6e38b2a9048c7799965948e34b90fa2fe37a6a3679427ff7a0b.

The verified Task85c-h source state was dirty=true at commit:

    65e6b99f07eea8241958ca746f205048e084bb4c.

Production freeze MUST build from the exact hash-bound implementation
closure above, or from a clean source state accompanied by a proof of
byte/source identity to that closure. A later changed worktree MUST NOT
be silently accepted as the same implementation.

The task must:

    verify and reuse the frozen scientific implementation without
        changing its scientific handlers;
    freeze DEVELOPMENT-derived calibration;
    materialize the production blind set and escrow;
    materialize natural confirmatory controls;
    instantiate the complete concrete DAG;
    validate distributed execution and determinism;
    qualify computational capacity;
    freeze the production executable;
    freeze the immutable run manifest and preseed;
    produce an operator handoff for Task86C-v2-run.

The production experiment itself MUST NOT be executed by this task.

Success means:

    PRODUCTION_RUN_AUTHORIZED = YES.

It does NOT mean that confirmatory scientific results have been
obtained.

    Hidden truth can leak or truth/control binding is unreliable.

RUN_INTEGRITY_DEFECT

    Concrete run cannot maintain one-to-one job/evidence/dependency
    integrity.

IMPLEMENTATION_VALIDATION_FAILURE

    Code disagrees with frozen scientific behavior.

DETERMINISM_FAILURE

    Scientifically identical executions produce scientifically
    different evidence.

CAPACITY_NOT_READY

    Frozen experiment cannot currently be executed with qualified
    resources.

SCIENTIFIC_FIREWALL_VIOLATION

    Confirmatory information was accessed or used before authorized
    execution/analysis.

Do not escalate harmless opaque representation choices into
SCIENTIFIC_CONTRACT_DEFECT.


======================================================================
39. FAILURE POLICY
======================================================================

On a non-scientific implementation/provenance ambiguity:

    choose a deterministic conventional representation;
    document it;
    add a regression test;
    continue.

On an ambiguity capable of changing the scientific result:

    STOP.

This distinction is normative for this task.

42. DEFINITION OF DONE
======================================================================

Task86C-v2-production-freeze is complete when one concrete
production run has been fully prepared, validated and frozen but
has not been scientifically executed.

At that point:

    scientific protocol is frozen;
    production implementation is validated;
    DEVELOPMENT calibration is frozen;
    blind controls exist but remain blind;
    escrow is sealed;
    natural confirmatory inputs exist but remain unevaluated;
    concrete JobIDs are frozen for this run;
    complete DAG is frozen;
    production executable is frozen;
    capacity is qualified;
    run manifest and preseed are frozen;
    operator runbook is complete.

Task86C-v2-run must then be a predominantly operational task:

    start the frozen coordinator/workers;
    submit the frozen manifest;
    permit deterministic execution/retry;
    verify complete evidence closure;
    freeze the resulting evidence.

No further scientific design or execution-identity refreeze is
required unless a defect is found that can materially alter the
scientific result, blindness, or concrete run integrity.
