State Machine Resolution

    E01 unregistered SCIENTIFIC_FAILURE

    E03 generation-failure action contradiction

5. CENTRAL SCIENTIFIC INVARIANT
======================================================================

Freeze the following invariant explicitly:

    EXECUTION/SCIENTIFIC-PROCEDURE FAILURE
        !=
    SCIENTIFIC FAIL

`FAIL` means:

    an authorized scientific gate/verifier was successfully evaluated
    and produced assessable negative evidence.

Failure to obtain valid scientific evidence must never itself become
evidence that a model/class is scientifically inadequate.


======================================================================
6. THREE DISTINCT SEMANTIC CATEGORIES
======================================================================

The state machine MUST explicitly distinguish at least:

A. SCIENTIFIC OUTCOME

    PASS
    FAIL

B. SCIENTIFIC MISSINGNESS / INASSESSABILITY

    NOT_ASSESSABLE

C. EXECUTION/PROCEDURE STATE

    FIT_FAILURE
    NUMERICAL_FAILURE
    INDUCTION_CAP
    GENERATION_FAILURE
    PROTOCOL_VETO
    NOT_REACHED

Do not collapse category C into FAIL.


======================================================================
7. PASS
======================================================================

Define PASS normatively as:

    successful completion of the relevant scientific gate/verifier
    with assessable evidence satisfying its frozen positive criterion.

PASS MUST NOT be emitted by:

    FIT
    model serialization
    generation merely succeeding
    DAG suppression
    infrastructure execution.


======================================================================
8. FAIL
======================================================================

Define FAIL normatively as:

    successful completion of the relevant scientific gate/verifier
    with assessable evidence failing its frozen scientific criterion.

FAIL MUST NOT mean:

    fit failed;
    numerical algorithm failed;
    induction exceeded cap;
    generation failed;
    protocol validation failed;
    job was suppressed;
    worker failed;
    evidence is missing.


======================================================================
9. NOT_ASSESSABLE
======================================================================

Define NOT_ASSESSABLE precisely.

It represents a scientifically specified condition under which the
requested scientific statistic/verdict cannot be assessed despite
the relevant procedure reaching the point where that condition can
be determined.

Examples must follow the existing frozen contract, such as PM6
saturation/coverage insufficiency where applicable.

Do not use NOT_ASSESSABLE as a generic replacement for every
execution failure unless that mapping is explicitly justified and
frozen.


======================================================================
10. NOT_REACHED
======================================================================

Define NOT_REACHED as a DAG/reachability state only.

It means:

    the planned job/cell exists in the frozen DAG but its scientific
    computation is suppressed by the frozen upstream state machine.

NOT_REACHED is not:

    PASS;
    FAIL;
    NOT_ASSESSABLE;
    worker failure;
    retry exhaustion.

It must identify the upstream state/reason that caused suppression.
