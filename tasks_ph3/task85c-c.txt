status/reachability correction V2, repair all A17 evidence schemas,
exhaustively validate their machine-enforceable semantics, and issue
one complete executable scientific contract revision:

    G1_V2_EXECUTABLE_CONTRACT_V1_1

This is the final contract-repair/refreeze task before:

    Task86C-v2-scientific-impl-R2.

This task is:

    CONTRACT INTEGRATION
    A17 SCHEMA REPAIR
    STANDARD JSON SCHEMA ENFORCEMENT
    EXHAUSTIVE EVIDENCE VALIDATION
    GOLDEN SUITE EXTENSION
    CONTROLLED EXECUTABLE CONTRACT REFREEZE

It is NOT:

    scientific redesign;
    status/reachability redesign;
    model implementation;
    production handler implementation;
    threshold construction;
    blind-control construction;
    production manifest construction;
    capacity benchmarking;
    scientific execution;
    natural confirmatory execution;
    Voynich evaluation.
