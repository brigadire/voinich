Task85c-i — G1-v2 V1.2 Evidence Schema and Execution-Identity
Integration Refreeze


PURPOSE

Resolve the two authority-integration defects discovered by Task85c-h:

    H-SC01-EVIDENCE-CONTRACT-VERSION
    H-SC02-E1-JOBID-SCIENTIFIC-VERSION

and produce a coherent V1.2-compatible evidence and execution-identity
authority layer without changing the scientific semantics of:

    G1_V2_EXECUTABLE_CONTRACT_V1_2.

Task85c-h established that production scientific implementation cannot
begin because the currently frozen authorities require mutually
exclusive scientific contract-version identities:

    current scientific contract:
        G1_V2_EXECUTABLE_CONTRACT_V1_2

    all 15 frozen evidence schemas:
        G1_V2_EXECUTABLE_CONTRACT_V1_1

    E1 contract_version:
        G1_V2_EXECUTABLE_CONTRACT_V1_1

    E1 jobid.scientific_identity_version:
        G1_V2_EXECUTABLE_CONTRACT_V1_1.

No implementation may choose between these values.

Task85c-i must repair the authority integration layer so that one
scientific V1.2 job has one unambiguous:

    scientific contract identity;
    JobID scientific identity;
    evidence contract identity;
    evidence schema family;
    canonical evidence representation.

The repair must preserve the already frozen V1.2 scientific content.

No production scientific handlers are implemented by this task.

No production materialization is performed by this task.
