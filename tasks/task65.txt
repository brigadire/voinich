Task65 — Local Regime Topology, Drift and Change-Point Analysis

Цель

Определить природу BROADER_LOCAL_REGIME, обнаруженного Task64.

Tasks 58–64 дают следующую рабочую картину:

    1. token-internal structure очень сильна;
    2. vocabulary имеет плотную локальную geometry;
    3. непосредственная token-to-token form dependence слаба;
    4. tokens локального участка текста систематически похожи;
    5. physical line boundary не является особой границей;
    6. similarity постепенно уменьшается с расстоянием;
    7. page boundary показывает значительно больший разрыв;
    8. сила эффекта существенно различается между
       discovery и replication subsets.

Task65 должен различить четыре основные гипотезы:

H1 — CONTINUOUS_DRIFT

    существует медленно меняющееся локальное состояние:

        R(x + Δ) ≈ R(x)

    и similarity плавно уменьшается с расстоянием.

H2 — DISCRETE_REGIMES

    существует небольшой набор повторяющихся состояний:

        R ∈ {R1, R2, ..., RK}

    между которыми текст переключается.

H3 — HIERARCHICAL_REGIMES

    локальная структура в значительной степени определяется:

        Currier
        Hand
        Section
        Page

    с дополнительной variation внутри этих уровней.

H4 — MIXED_DRIFT_AND_STATES

    существуют крупные дискретные regimes,
    внутри которых наблюдается локальный drift.

Task65 НЕ должен заранее выбирать одну из этих моделей.

НЕ выполнять decipherment.
НЕ интерпретировать regimes как topics, language states или cipher keys.
НЕ добавлять Stage29.
НЕ изменять Stages 1–28.

======================================================================
1. PRIMARY QUESTIONS
======================================================================

Ответить:

1. Насколько local similarity зависит от физического расстояния?

2. Затухает ли она плавно?

3. Существуют ли статистически подтверждаемые abrupt change points?

4. Повторяются ли похожие regimes в удалённых частях manuscript?

5. Насколько regime structure объясняется:

       Currier A/B
       Hand
       Section
       Page?

6. Существует ли residual local regime после conditioning на metadata?

7. Чем объясняется сильное различие discovery/replication Task64?

======================================================================

7. WINDOW STEP
======================================================================

Для fixed-token windows использовать заранее фиксированный step.

Например:

    step = W/4

или другой единый deterministic rule.

Не создавать окно на каждый token, если это приводит к
псевдорепликации без необходимости.

======================================================================
8. REGIME FEATURE VECTOR
======================================================================

Для каждого window построить compact structural profile.

Использовать только заранее определённые features, например:

    mean token length
    token-length distribution

    initial glyph distribution
    final glyph distribution

    selected glyph frequencies

    positional-region distributions

    mean d1 neighborhood degree
    giant-family fraction

    local exact-repeat rate
    local near-repeat opportunity

    selected Task61 entropy-compatible statistics,
    только если sample size достаточен.

Не использовать exact token identities как основной feature space.

======================================================================
9. SPARSITY SAFEGUARD
======================================================================

Не включать тысячи token/glyph dimensions.

Feature set должен быть:

    low-dimensional
    stable
    interpretable.

Для sparse categorical distributions применять predefined smoothing.

10. FEATURE NORMALIZATION
======================================================================

Normalization parameters оценивать только на TRAIN/DISCOVERY.

Не нормализовать каждый window независимо таким образом,

======================================================================

Например:

или существующий authoritative Task64 profile distance.

Secondary distances допустимы как sensitivity analysis.

Не выбирать metric по результату.

======================================================================
12. AUTOCORRELATION / DISTANCE DECAY
======================================================================

Вычислить:

    D(R_x, R_x+k)

Отдельно:

    token lag
    line lag
    page lag.

Получить:

    LOCAL_REGIME_DECAY.tsv

    median
    CI

======================================================================
13. CORRELATION LENGTH
======================================================================

Оценить characteristic local scale:

    L_corr

без предположения о конкретной физической интерпретации.

Например:

    расстояние, на котором excess similarity падает
    до 1/e или 50% initial excess.

Definition зафиксировать до анализа.

======================================================================
14. DO NOT FORCE EXPONENTIAL DECAY
======================================================================

Не предполагать:

    similarity ~ exp(-x/L).

Сначала показать empirical curve.

Exponential/linear/piecewise fits использовать только как
descriptive secondary models.

======================================================================
15. SAME-PAGE VS CROSS-PAGE
======================================================================

Для одинакового token/line separation, где возможно, сравнить:

    same-page windows

с:

    cross-page windows.

Проверить, существует ли page-boundary discontinuity сверх
обычного distance decay.

======================================================================
16. PAGE-BOUNDARY EFFECT
======================================================================

Определить:

    Δ_page_boundary =
        observed profile distance across page boundary
        -
        expected distance at comparable local separation.

Это лучше простого сравнения raw distances.

======================================================================
17. LINE-BOUNDARY EFFECT
======================================================================

Аналогично:

    Δ_line_boundary.

Task64 предполагает:

    Δ_line_boundary ≈ small.

Task65 должен независимо это проверить.

======================================================================
18. CHANGE-POINT ANALYSIS
======================================================================

Проверить наличие abrupt changes в последовательности window profiles.

Использовать минимум один простой deterministic method:

    cumulative/profile-distance change score

и один formal change-point method, если уже доступен или
реализуется без чрезмерной сложности.

Не использовать neural segmentation.

======================================================================
19. CHANGE-POINT NULL
======================================================================

Change-point detector обязательно калибровать на null corpora,
где существует:

    smooth drift without true boundaries

и:

    stationary local process.

Иначе любой noise будет давать "regime boundaries".

======================================================================
20. SYNTHETIC POSITIVE CONTROL — DISCRETE
======================================================================

Создать corpus/profile sequence:

    R1 R1 R1 R2 R2 R2 R3 R3 ...

с известными boundaries.

Analyzer должен восстанавливать boundaries с заранее установленной
точностью.

======================================================================
21. SYNTHETIC POSITIVE CONTROL — DRIFT
======================================================================

Создать sequence, где parameters плавно меняются:

    R(x+1) = R(x) + small perturbation.

Change-point analyzer НЕ должен превращать smooth drift
в большое число дискретных regimes.

======================================================================
22. SYNTHETIC MIXED CONTROL
======================================================================

Создать:

    discrete macro-state
        +
    smooth drift внутри macro-state.

Analyzer должен различать оба уровня хотя бы статистически.

======================================================================
53. CONTINUOUS_DRIFT CRITERIA
======================================================================

Поддержка CONTINUOUS_DRIFT требует:

    significant smooth distance decay;

    отсутствие устойчивого малого K clusters
    ИЛИ substantial within-cluster drift;

    change-point density не превышает expectation smooth-drift
    control существенно.

======================================================================
54. DISCRETE_REGIME CRITERIA
======================================================================

Поддержка DISCRETE_REGIMES требует:

    stable clustering;

    replicated separation;

    dwell structure выше shuffled null;

    abrupt transitions;

    weak within-state distance decay относительно between-state
    difference.

======================================================================
55. HIERARCHICAL CRITERIA
======================================================================

Поддержка HIERARCHICAL_REGIMES требует:

    Currier/Hand/Section/Page объясняют substantial profile variance;

    но хотя бы один lower-level residual component может оставаться.

Не задавать произвольный процент "substantial" после анализа;
threshold preregister.

======================================================================
56. MIXED CRITERIA
======================================================================

MIXED_DRIFT_AND_STATES:

    stable macro-states существуют

И

    significant local drift сохраняется внутри них.

======================================================================
57. POSSIBLE MULTIPLE CLASSIFICATION

    HIERARCHICAL + CONTINUOUS_DRIFT

или:

    HIERARCHICAL + MIXED.

Manuscript может иметь несколько scales организации.

65. CRITICAL RESULT A
======================================================================

Если после conditioning на:

    Currier
    Hand
    Section
    Page

локальный distance decay исчезает:

    BROADER_LOCAL_REGIME Task64 в основном является manifestation
    известных manuscript partitions.

Это важный negative result.

======================================================================
66. CRITICAL RESULT B
======================================================================

Если decay сохраняется даже:

    within same page

то существует настоящий sub-page local structural effect,
который нельзя объяснить Currier/Hand/Section/Page.

Это особенно сильный результат.

======================================================================
67. CRITICAL RESULT C
======================================================================

Если stable regimes повторяются в удалённых местах manuscript:

    local variation нельзя объяснить только monotonic scribal drift
    или manuscript position.

Это делает discrete/recurring state hypothesis значительно сильнее.

======================================================================
68. CRITICAL RESULT D
======================================================================

Если profile плавно изменяется с position, clusters нестабильны,
