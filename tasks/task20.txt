Задача: residual-diagnostic-analyze

Цель

Объяснить, почему после metadata residualization

    R_w = X_w - μ_(Currier,Hand)

residual clusters всё ещё сильно ассоциированы с Currier:

    original Currier NMI ≈ 0.713
    residual Currier NMI ≈ 0.719

при том что residual clustering сам по себе НЕ превосходит null:

    k-medoids raw residual:
        observed silhouette ≈ 0.330
        null mean ≈ 0.407
        effect size ≈ -11.14
        empirical p = 1.0

Не выполнять новый discovery.
Не подбирать новые window sizes, K или признаки.

Это диагностический эксперимент.

2. Главный вопрос
============================================================

Mean-centering по Currier×hand должен удалить различия средних feature
vectors между metadata classes.

Но это НЕ гарантирует удаления различий:

    variance
    covariance
    dispersion
    feature sparsity
    block identity
    temporal position

Нужно установить, какой именно источник позволяет residual representation
всё ещё различать Currier.


============================================================
PART A — VERIFY RESIDUALIZATION
============================================================

3. Проверить centering математически

Для каждого joint Currier×hand class и каждого window size:

рассчитать средний raw residual vector:

    mean(R_w | C,H)

Сохранить:

    L1 norm
    L2 norm
    max absolute component
    mean absolute component

Если residualization реализована правильно, training residual means должны
быть близки к numerical zero.


4. Training vs held-out

Поскольку μ_(C,H) вычислялась только по training folds, отдельно показать:

    training residual mean
    held-out residual mean

Это принципиально.

Held-out mean не обязан быть нулём.

Нужно измерить magnitude этого drift.


5. Fold diagnostics

Для каждого:

    joint_class

вывести:

    training windows
    test windows
    ||mean_train_residual||
    ||mean_test_residual||

Проверить, не возникает ли residual Currier signal преимущественно из
train/test distribution shift.

============================================================
PART F — WHITENING DIAGNOSTIC
============================================================

21. Joint-class whitening

Следующий заранее определённый transformation:

Для каждого Currier×hand class на training data:

    μ_(C,H)
    Σ_(C,H)

Преобразовать:

    Z_w =
        Σ_(C,H)^(-1/2)
        (X_w - μ_(C,H))

Использовать regularized covariance.


22. Regularization

Не подбирать lambda.

Использовать заранее фиксированную shrinkage scheme:

    Σ_reg =
        0.9 Σ
        + 0.1 diag(Σ)

Если матрица всё ещё singular:

    eigenvalue floor =
        1e-6 × largest_eigenvalue

Все параметры записать в report.


23. No leakage

μ и Σ вычислять исключительно на training physical blocks/folds.

Held-out windows преобразуются training estimates.


24. После whitening

НЕ выполнять полный search K=2..15.

Использовать только заранее существующий winning diagnostic:

    window = 500
    K = 2
    k_medoids

27. Block association

28. Conditional on joint metadata

29. Leave-one-block-out recurrence

Для каждого sufficiently large physical block:

    exclude block
    derive representation/clustering from remaining blocks
    assign excluded windows to nearest medoids

Считать:

    assignment confidence
    medoid distance
    whether both residual regimes recur in held-out block


30. Главный критерий recurrence

Режим считается cross-block recurring только если:

    аналогичный cluster присутствует минимум в 2 independent physical blocks

и similarity к medoid превышает заранее используемый within-cluster
reference threshold.

Не считать один большой contiguous block самостоятельным
"reproducible regime".

============================================================
PART K — REPORT DECISION TREE
============================================================

40. Outcome A — centering bug

Если training residual means существенно не равны zero:

    residualization implementation error

Остановить интерпретацию Part B предыдущего эксперимента.


41. Outcome B — held-out mean drift

Если:

    train residual ≈ 0
    test residual != 0

и linear classifier восстанавливает metadata:

вывод:

    metadata distributions are non-stationary across physical blocks;
    a single class mean does not generalize across blocks.


42. Outcome C — covariance/dispersion effect

Если:

    mean residual ≈ 0
    linear metadata prediction weak
    norm/covariance diagnostics strong
    whitening sharply reduces metadata NMI

вывод:

    residual metadata association is primarily second-order.


43. Outcome D — physical block effect

Если existing residual cluster:

    dominated by one block

и cross-block recurrence отсутствует:

вывод:

    apparent residual regime is block-specific, not recurrent.


44. Outcome E — metadata survives whitening

Если после leakage-safe whitening:

    Currier/hand NMI остаётся высоким

нужно остановиться.

Не выполнять дальнейший regime discovery.

Это означает, что текущая conditioning model недостаточна.


45. Outcome F — metadata removed

Если whitening:

    strongly reduces Currier/hand/joint NMI

и residual structure всё ещё воспроизводится между independent blocks:

только тогда оправдан следующий residual discovery experiment.
