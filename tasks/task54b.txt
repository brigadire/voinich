Task54b — Voynich inverse-transposition effect measurement and holdout validation

Цель

Проверить, действительно ли найденный на discovery search кандидат

    width = 2
    order = natural

восстанавливает статистическую последовательную структуру Voynich,
или его первое место является следствием candidate-local min-max
normalization и малых случайных различий между candidates.

ВАЖНО:

    НЕ выполнять новый поиск параметров.
    НЕ менять structural-v2.
    НЕ менять weights.
    НЕ расширять widths/orders.
    НЕ запускать полный scientific pipeline.

Discovery уже завершён. Победитель зафиксирован:

    width=2
    order=natural

Задача является validation/effect-measurement, а не новым search.

======================================================================
1. ORIGINAL VOYNICH BASELINE
======================================================================

Тем же evaluator, который использовался inverse-transposition-search,
вычислить для НЕПРЕОБРАЗОВАННОГО canonical Voynich corpus четыре raw
компонента structural-v2:

    transition
    relation
    sequence-2
    sequence-3

Использовать ровно тот же corpus SHA256, что использовался в
voynich-discovery.

Никаких преобразований original corpus.

======================================================================
2. ABSOLUTE EFFECT
======================================================================

Для каждого уже существующего discovery candidate вычислить относительно
original Voynich:

    delta_absolute = metric(candidate) - metric(original)

и, где denominator корректен:

    delta_relative =
        (metric(candidate) - metric(original)) / metric(original)

Создать таблицу:

    candidate
    width
    order

    transition_raw
    transition_delta
    transition_relative_delta

    relation_raw
    relation_delta
    relation_relative_delta

    sequence2_raw
    sequence2_delta
    sequence2_relative_delta

    sequence3_raw
    sequence3_delta
    sequence3_relative_delta

Особенно явно показать:

    original
    w2 natural
    w2 keyed
    следующие top candidates.

======================================================================
3. НЕ ИСПОЛЬЗОВАТЬ DISCOVERY MIN-MAX КАК EFFECT SIZE
======================================================================

Текущий structural-v2 использует min-max normalization по candidate set.

Он остаётся неизменным как зарегистрированный SEARCH/RANKING objective.

Но:

    structural-v2 discovery score НЕ интерпретировать как величину
    физического эффекта.

То есть:

    score(w2)=0.6735

не означает improvement 67%.

В validation report отделить:

    SEARCH SCORE

от:

    RAW EFFECT SIZE.

======================================================================
4. FIXED CALIBRATION EFFECT SCORE
======================================================================

Если calibration data Task54 для Doyle/T2/T4/T8 сохранены, построить
дополнительный POST-HOC effect score с фиксированной шкалой.

Шкала должна определяться ТОЛЬКО pre-Voynich calibration controls.

Например использовать заранее полученные ranges/scales:

    Doyle
    T2(Doyle)
    T4(Doyle)
    T8(Doyle)

Никакие Voynich candidates не должны участвовать в определении
normalization parameters.

Назвать метрику явно иначе, например:

    fixed_calibration_effect_score

Это НЕ замена structural-v2 и НЕ новый search objective.

Это только post-search measurement.

Если корректную fixed calibration невозможно восстановить из сохранённых
pre-Voynich artifacts — НЕ придумывать её заново и не подбирать шкалу по
Voynich.

В таком случае оставить только raw deltas и документировать причину.

======================================================================
5. WIDTH=2 SPECIAL-EFFECT AUDIT
======================================================================

Discovery показал необычно высокий sequence-3 для w2 natural:

    sequence3 ≈ 0.003581

при значительно меньших значениях большинства других candidates.

Проверить, не является ли это механическим свойством width=2
transposition.

Для этого использовать natural-text controls, НЕ Voynich tuning.

Минимально:

    Doyle original
    T2(Doyle)

и, если уже доступны:

    Longfellow
    Astafiev
    другие natural corpora.

Сравнить:

    original -> inverse-w2

на untransformed corpus и соответствующие known-transposition controls.

Ответить:

    создаёт ли width=2 повышенный repeated-trigram/sequence3 signal
    сам по себе?

Не менять transformation на основании результата.

======================================================================
6. DISCOVERY / HOLDOUT SPLIT
======================================================================

Использовать deterministic split Voynich, предусмотренный Task54.

Если split уже зафиксирован manifest/documentation — использовать его
без изменений.

Если split был реализован, но не материализован — материализовать
строго существующее правило.

Если правило split вообще не было заранее определено, НЕ выбирать split,
ориентируясь на результаты w2.

Использовать простое deterministic правило, максимально сохраняющее
существующие logical boundaries, и явно отметить это как limitation.

Создать:

    discovery corpus
    holdout corpus

с SHA256 обоих.

10. NULL CONTROL
======================================================================

Использовать существующий Task54 null/random framework.

Для holdout выполнить null transformations с тем же computational budget,
который предусмотрен Task54.

Но НЕ использовать null search для выбора нового theta.

Цель:

    определить, насколько effect фиксированного w2 отличается от
    распределения эффектов случайных допустимых transformations.

Зафиксировать:

    null mean
    null median
    null quantiles
    empirical percentile w2

по каждой диагностической metric и, если корректно, fixed-calibration
composite.

======================================================================
12. RESULT CLASSIFICATION
======================================================================

В отчёте классифицировать результат консервативно.

STRONG SUPPORT:

    несколько transposition-sensitive raw metrics улучшаются на discovery;
    те же metrics улучшаются в том же направлении на holdout;
    effect заметно превосходит null;
    fixed w2 работает без переоптимизации.

WEAK/MIXED:

    часть metrics переносится на holdout;
    часть нет;
    effect небольшой или сравним с null.

NEGATIVE:

    discovery improvement исчезает/меняет направление на holdout;
    либо raw effect оказывается практически нулевым;
    либо w2 не отличается от null transformations.

Не использовать формулировки:

    decrypted
    deciphered
    plaintext recovered.
