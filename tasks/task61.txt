Task61 — Character Conditional Entropy and Hierarchical Structure Analysis

Цель

Независимо воспроизвести опубликованное наблюдение о низкой
character-level conditional entropy Voynich и определить, как оно
соотносится с результатами Tasks 58–60.

Основные вопросы:

1. Действительно ли Voynich имеет существенно более низкую
   character/glyph conditional entropy, чем естественные тексты?

2. На каком порядке контекста возникает различие:

       h1
       h2
       h3
       h4
       ...

3. Является ли низкая entropy следствием:
       - структуры внутри tokens;
       - token boundaries;
       - line boundaries;
       - positional specialization glyphs;
       - ограниченного набора допустимых token forms?

4. Сочетается ли низкая glyph-level entropy с уже обнаруженной
   слабой token-order dependency?

5. Стабилен ли этот fingerprint между:
       Currier A
       Currier B
       manuscript sections
       scribes/hands,
   насколько это позволяет metadata?

6. Может ли простая position-independent homophony воспроизвести
   одновременно:
       weak token-order dependency
   и
       low glyph conditional entropy?

Task61 является независимым исследованием.

НЕ добавлять новый stage в Stages 1–28.
НЕ использовать Task52 fingerprint как optimization target.
НЕ подбирать параметры по близости к Voynich.

5. ENTROPY REDUCTION
======================================================================

    Δ3 = h2 - h3

как меру дополнительной predictability, создаваемой каждым уровнем
контекста.

Это важно, поскольку абсолютное h2 зависит от размера glyph alphabet.

7. BOUNDARY REPRESENTATIONS
======================================================================

Провести анализ минимум в трёх режимах.

A. CONTINUOUS

    tokens соединяются в glyph stream;
    whitespace не является glyph.

B. TOKEN_BOUNDARY

    между tokens вставляется специальный symbol:

        <WB>

C. WITHIN_TOKEN_ONLY

    transitions/context не пересекают token boundaries.

Это критически важно.

Если низкое h2 Voynich создаётся главным образом внутренней структурой
tokens, ожидается:

======================================================================
11. BIAS / SPARSITY CONTROL
======================================================================

Высокопорядковые entropy estimates имеют downward finite-sample bias.

Использовать correction, если он предусмотрен primary literature.

Дополнительно разрешается OUR_EXTENSION:

    bootstrap;
    held-out cross entropy;
    Miller-Madow;
    Bayesian estimator;
    another preregistered correction.

Но разные estimators хранить отдельно.

Не интерпретировать падение h5/h6 как структуру, если contexts почти
все уникальны.

13. SHUFFLE NULL B — WITHIN-TOKEN
======================================================================

======================================================================
14. SHUFFLE NULL C — TOKEN SHUFFLE
======================================================================

Перемешать целые tokens.

Сохраняются:

    vocabulary
    token frequencies
    internal glyph structure.

Уничтожается:

    token sequence.

Если character entropy почти не изменится:

    основной источник predictability находится внутри token forms,
    а не между tokens.

Это один из центральных tests Task61.
