Задача: replicated-local-structure-audit

Цель

Провести confirmatory audit двух классов результатов
cross-metadata-token-relation-validate:

A. distance-profile relations, которые имеют статистически значимую
   cross-block replication, но не получили UNIVERSAL classification;

B. sequence relations, среди которых 104 получили UNIVERSAL classification.

НЕ выполнять новый unrestricted discovery.
НЕ добавлять новые token pairs, n-grams, distances или thresholds.
НЕ изменять существующие classification rules задним числом.

Главный вопрос:

    Содержат ли уже frozen результаты воспроизводимую локальную структуру,
    которую существующая классификация либо недооценивает
    (distance profiles), либо переоценивает (sequences)?

7. BLOCK-LEVEL PROFILE REPLICATION
================================================================

Для каждого q<=0.05 candidate показать каждый physical block отдельно:

    block
    Currier
    hand
    joint class
    token counts A/B
    observations
    similarity
    similarity_to_LOBO_reference
    transfer_success


================================================================
8. LEAVE-ONE-BLOCK-OUT PROFILE
================================================================

Primary replication statistic:

для каждого eligible block:

    reference profile =
        aggregate profile from all OTHER eligible blocks

затем:

    similarity(
        held-out block profile,
        reference profile
    )

Никакого held-out leakage.


================================================================
9. EFFECT RELATIVE TO NULL
================================================================

Абсолютное similarity может быть маленьким и всё же систематически
превышать expected similarity случайных frequency-matched pairs.

Поэтому для каждого held-out block считать:

    observed_similarity
    null_mean
    null_sd
    null_p95
    null_p99

и:

    standardized_similarity =
        (observed - null_mean) / null_sd


================================================================
10. НЕ ПОДМЕНЯТЬ ABSOLUTE И RELATIVE EFFECT
================================================================

Хранить отдельно:

    absolute profile similarity

и:

    similarity relative to null.

Не создавать один score.


================================================================
11. CROSS-METADATA TRANSFER
================================================================

Для каждого significant pair отдельно проверить:

    within-Currier transfer
    cross-Currier transfer

    within-hand transfer
    cross-hand transfer

    within-joint transfer
    cross-joint transfer


================================================================
12. META-ANALYTIC SIGN CONSISTENCY
================================================================

Для каждого block определить:

    effect =
        observed_similarity - null_mean

Посчитать:

    positive_effect_blocks
    negative_effect_blocks
    effect_sign_consistency

и weighted/unweighted mean standardized effect.


================================================================
13. BLOCK CONCENTRATION
================================================================

Проверить, не создаётся ли significance одним большим block.

Вывести:

    observations_per_block
    max_block_observation_fraction
    max_block_effect_contribution


================================================================
14. JACKKNIFE
================================================================

Для каждого significant relation:

по очереди исключить каждый physical block
и повторно рассчитать aggregate replication statistic.

Вывести:

    full_effect
    min_jackknife_effect
    max_jackknife_effect
    jackknife_sd

и:

    significance_survives_each_block_removal

Последнее descriptive:
НЕ пересчитывать новый FDR после каждого удаления.


================================================================
15. DISTANCE-SHAPE CONSISTENCY
================================================================

Использовать только frozen distances:

    ±1..±20

Для каждого block сохранить нормированный профиль по distance.

Проверить:

    peak distance
    center of mass
    left/right asymmetry

Не вводить новые optimization criteria.


================================================================
16. PROFILE SHAPE TRANSFER
================================================================

Проверить отдельно:

A.
    magnitude similarity

B.
    shape similarity after unit normalization

Это diagnostic.

Если absolute magnitude различается между blocks,
но normalized shape воспроизводится,
это отдельный содержательный результат.


================================================================
17. DISTANCE-PROFILE OUTCOME LABELS
================================================================

Не менять старую classification.

Создать НОВОЕ diagnostic поле:

    replication_status

со значениями:


ROBUST_RELATIVE_REPLICATION

    q <= 0.05
    eligible blocks >= 3
    joint classes >= 2
    LOBO transfer >= 0.67
    positive null-relative effect >=75% blocks
    jackknife does not collapse


METADATA_LIMITED_REPLICATION

    significant replication,
    но перенос ограничен Currier/hand/joint class


SINGLE_BLOCK_DRIVEN

    effect collapses after removing one block
    или evidence dominated by one block


STATISTICALLY_SIGNIFICANT_BUT_UNSTABLE

    q <= 0.05
    но cross-block consistency insufficient


NOT_SIGNIFICANT

    q > 0.05


Эти labels являются diagnostic и НЕ заменяют предыдущие
UNIVERSAL/WEAK/BLOCK_SPECIFIC.

================================================================
27. EXPECTED RECURRENCE
================================================================

Сам факт повторения короткого bigram/trigram в нескольких blocks
может быть тривиален из-за частоты tokens.

Для каждой UNIVERSAL sequence построить frequency-aware null.


================================================================
28. NULL MODEL A — WITHIN-BLOCK TOKEN SHUFFLE
================================================================

Для каждого physical block:

    shuffle token order внутри block

Сохранять:

    token frequencies
    block lengths
    metadata composition

Не перемещать tokens между blocks.


================================================================
29. NULL MODEL B — FIRST-ORDER MARKOV
================================================================

Secondary diagnostic.

Для каждого physical block построить first-order transition model
на training material.

Генерировать sequences той же длины блока.

Это сохраняет:

    unigram frequencies
    approximate bigram structure

и проверяет, содержит ли recurrence информацию выше первого порядка.


================================================================
30. NO LEAKAGE FOR MARKOV NULL
================================================================

Для held-out block transition probabilities оценивать
по другим blocks того же metadata class, если support достаточен.

Если невозможно:

    Markov result = NA

Не fallback на held-out training.

    total occurrences

33. EMPIRICAL P
================================================================

Использовать:

    p = (exceedances + 1) / (permutations + 1)

    1000 permutations


================================================================

================================================================

    within-block shuffle null

Markov null оставить secondary.

================================================================
40. ОСНОВНОЙ ИССЛЕДОВАТЕЛЬСКИЙ ВОПРОС
================================================================

Нужно различить три ситуации:


A. NOTHING REMAINS

Distance-profile significance нестабильна,
а UNIVERSAL sequences объясняются frequency/null/artifacts.

Вывод:

    no convincing transferable local structure remains
    under current tests.


B. DISTANCE STRUCTURE REMAINS

Distance profiles:

    survive FDR
    survive jackknife
    reproduce across blocks
    transfer across metadata
    exceed frequency-matched null

Вывод:

    weak but reproducible relative-distance organization exists.


C. HIGHER-ORDER SEQUENCES REMAIN

Некоторые n>=3 sequences:

    recur across independent blocks
    survive within-block shuffle
    survive FDR
    preferably exceed first-order Markov expectation

Вывод:

    reproducible higher-order sequential organization exists.


D. BOTH REMAIN

Тогда проверить, относятся ли significant sequences
и significant distance profiles к одним token families.

Но это только descriptive follow-up.
Не проводить новый significance search.

ГЛАВНАЯ ЦЕЛЬ
================================================================

Не искать новые закономерности.

Нужно выяснить, что реально осталось после предыдущей жёсткой
cross-metadata validation.

В частности:

1. Являются ли FDR-significant distance-profile relations
   устойчивой cross-block структурой, несмотря на низкую absolute
   similarity?

2. Являются ли 104 UNIVERSAL sequences действительно неожиданно
   повторяющимися последовательностями, либо их recurrence объясняется
   частотами токенов, короткой длиной, metadata/block composition
   или transcription artifacts?

Только после этого решать, какой тип локальной структуры имеет смысл
исследовать дальше.
