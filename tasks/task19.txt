Задача: Conditional residual distributional structure after controlling
for Currier and Davis hand

Контекст

Blind global distributional discovery обнаружил устойчивую структуру корпуса.

Последующая metadata validation показала:

1. Strong blind boundaries слабо совпадают непосредственно с Currier/hand
   transitions.

2. Blind distributional regimes, напротив, существенно ассоциированы
   с Currier и Davis hand.

3. После global multiple-comparison correction по всему заранее frozen
   search space:

   window_size ∈ {50,100,200,500,1000}
   method ∈ {
       contiguous_segmentation,
       hierarchical,
       k_medoids
   }
   K ∈ 2..15

   Currier:
       global max NMI = 0.713
       empirical p = 0.0008

   Hand:
       global max NMI = 0.631
       empirical p = 0.0104

4. Особенно устойчив k_medoids:
   association воспроизводится на нескольких window scales.

Следующий исследовательский вопрос:

Существует ли distributional structure корпуса, которая НЕ объясняется
Currier и Davis hand?

Иными словами:

    observed token distribution
            =
    Currier effect
    + hand effect
    + possible residual structure

Нужно проверить последний компонент.


ВАЖНО

Это НОВЫЙ эксперимент.

Его параметры должны быть зафиксированы сейчас и после просмотра результатов
не изменяться.

Не использовать результаты этого эксперимента для подбора window sizes,
K, thresholds или conditioning strategy.


1. Входные данные

Canonical corpus:

    data_work/ZL3b-x7.txt

token_count:

    39026

SHA256:

    360d99583145ec549b80edfafdc3f93534f3a11b85a0d52997ba8425e92b87c2

Metadata:

    workdir/metadata-validation/token_metadata_map.tsv

Использовать также frozen outputs:

    workdir/global_distributional_*
    workdir/metadata-validation/cluster_metadata_*

но только как reference/results.

Новый residual discovery выполнять независимо.


2. Не изменять canonical corpus

Token sequence остаётся неизменной.

Не удалять:

- unknown tokens;
- rare tokens;
- '?' tokens;
- @NNN tokens.

Metadata используется только для conditioning.


3. Основной принцип

Нельзя просто удалить Currier/hand boundaries и снова запустить прежний
анализ.

Нужно проверить структуру ВНУТРИ metadata-controlled subsets.

Primary conditioning variable:

    joint class = Currier × hand


4. Почему joint conditioning

Currier и hand статистически не независимы.

Поэтому отдельное:

    control Currier

и:

    control hand

не гарантирует устранения их совместного эффекта.

Primary analysis:

    condition on (Currier, hand)

Secondary analyses:

    Currier only
    hand only


5. Joint metadata classes

Для каждого token определить:

    joint_metadata_class =
        (currier, hand)

Например:

    A/H1
    A/H2
    B/H1
    B/H3
    ...

Unknown Currier не включать в primary Currier×hand analysis.

Unknown hand также исключать.

Не создавать:

    UNKNOWN/Hx

как реальный metadata class.


6. Не смешивать несмежные блоки автоматически

Каждый contiguous run одного joint metadata class сначала считать
отдельным physical block.

Например:

    A/H1 block #1
    A/H1 block #2

не соединять физически в один artificial text stream для анализа
локальных переходов.


7. Два complementary residual experiments

Реализовать два подхода:

A. WITHIN-CLASS DISCOVERY

Искать distributional regimes внутри metadata-controlled material.

B. METADATA-RESIDUALIZED FEATURES

Удалить ожидаемую distributional component Currier×hand из window
representation и искать структуру в residual feature space.

Оба анализа нужны, поскольку отвечают на несколько разные вопросы.


============================================================
PART A — WITHIN-CLASS DISCOVERY
============================================================


8. Eligible joint classes

Joint class включать в анализ только если имеется достаточный объём текста.

Primary threshold:

    minimum total tokens = 1000

Дополнительно:

    minimum contiguous block = 500 tokens

Порог зафиксирован заранее.

Вывести все classes и указать:

    eligible / ineligible


9. Class inventory

Создать:

    conditional_class_inventory.tsv

Поля:

currier
hand
joint_class
total_tokens
block_count
largest_block
median_block
eligible


10. Window sizes

Использовать только уже существующие scales:

    50
    100
    200
    500

Не использовать 1000 для primary within-class discovery,
поскольку controlled blocks могут быть слишком короткими.

Но если block >=3000 tokens, window=1000 разрешён только как
secondary diagnostic.

Не добавлять новые размеры окна.


11. Window boundaries

Window НИКОГДА не должен пересекать:

- Currier transition;
- hand transition;
- joint-class transition.

Каждое window полностью принадлежит одному controlled block.


12. Window representation

Использовать ту же distributional representation, что использовалась
global-regime-analyze.

Не вводить новые признаки.

Цель — проверить прежний тип структуры после conditioning,
а не создать новый classifier.


13. Clustering methods

Primary:

    k_medoids

Причина:

именно unconstrained k_medoids показал наиболее устойчивую multi-scale
association в предыдущем validation.

Secondary:

    hierarchical

Contiguous segmentation использовать отдельно для boundary diagnostics,
но не как primary residual clustering.


14. K

Использовать:

    K = 2..10

Не расширять после просмотра результатов.

Для маленьких classes автоматически ограничивать:

    K <= floor(number_of_windows / 20)

и записывать фактический allowed K.


15. Within-class clustering

Для каждого eligible joint class:

    for window_size:
        50,100,200,500

        cluster windows
        independently inside this class.

Не разрешать информации других metadata classes влиять на clustering.


16. Residual regime strength

Для каждого:

    joint_class × window × method × K

считать минимум:

- silhouette;
- medoid separation;
- within-cluster dispersion;
- between-cluster dispersion;
- cluster size entropy;
- smallest cluster fraction.


17. Stability

Нужно проверить, воспроизводятся ли residual regimes.

Использовать contiguous block cross-validation.

Если joint class имеет несколько physical blocks:

    train/discover on subset of blocks
    test assignment/separation on held-out blocks.

Если имеется только один большой block:

    использовать contiguous folds,
    не random windows.


18. Cross-block recurrence

Особенно интересны regimes, которые появляются:

    в нескольких несмежных blocks
    одного Currier×hand class.

Считать:

- number of blocks containing regime;
- fraction of blocks;
- recurrence strength;
- medoid/profile similarity across blocks.


19. Negative control

Для каждого joint class построить shuffled controls.

Важно сохранять:

- token frequencies;
- block lengths;
- window lengths.

Минимум два null models.


20. Null A — within-block token shuffle

Перемешать tokens внутри каждого controlled physical block.

Это разрушает последовательную структуру, сохраняя unigram frequencies.


21. Null B — window-order shuffle

Сохранить реальные windows, но случайно изменить их порядок внутри block.

Это сохраняет local window distributions, но разрушает trajectory/regime order.

Использовать для boundary/trajectory statistics.


22. Permutations

Primary:

    1000 permutations

для discovery diagnostics.

Для наиболее сильных заранее определённым правилом candidates:

    10000 permutations

Candidate selection rule должен быть формальным и записан ДО запуска
10k refinement.


============================================================
PART B — METADATA-RESIDUALIZED FEATURE SPACE
============================================================


23. Цель

Проверить, остаётся ли структура после математического удаления средней
distributional signature Currier×hand.

Это отличается от Part A:

Part A анализирует каждый metadata class отдельно.

Part B позволяет сравнивать residual states между разными classes.


24. Base window representation

Использовать те же global windows/features, что и global-regime-analyze.

Для каждого window имеется feature vector:

    X_w


25. Expected metadata vector

Для каждого joint Currier×hand class вычислить expected feature vector:

    μ_(C,H)

Только по training data соответствующего fold.

Критически важно:

не вычислять expectation по всему corpus перед cross-validation.


26. Residual vector

Основная residualization:

    R_w = X_w - μ_(C,H)

То есть из каждого window representation удалить среднюю signature
его metadata class.


27. Standardized residual

Дополнительно secondary representation:

    Z_w = (X_w - μ_(C,H)) / σ_(C,H)

с regularization для малых variance.

Primary representation:

    raw residual R_w

Standardized residual:

    sensitivity analysis.


28. No metadata leakage

При cross-validation:

μ и σ рассчитываются только на training blocks.

Held-out windows residualize относительно training estimate.

Никакого использования held-out distribution для centering.


29. Residual global clustering

После residualization объединить residual windows разных metadata classes
и выполнить:

    k_medoids
    K = 2..15

на scales:

    50
    100
    200
    500
    1000

Это новый заранее frozen search space.


30. Основной вопрос

Возникают ли residual clusters, которые:

- устойчивы между scales;
- появляются в нескольких Currier classes;
- появляются у нескольких hands;
- появляются в несмежных частях corpus?


31. Metadata independence check

Для residual clusters снова вычислить association с:

    Currier
    hand
    Currier×hand

Ожидается, что association существенно снизится.

Если residual clusters всё ещё сильно предсказывают metadata,
residualization считается неполной.


32. Quantify removal

Сравнить:

    NMI(original regimes, Currier)
vs
    NMI(residual regimes, Currier)

и аналогично hand.

Вывести:

    metadata_information_reduction


33. Cross-metadata recurrence

Для каждого residual regime считать:

number of Currier classes
number of hands
number of joint classes
number of physical blocks

и entropy распределения metadata внутри regime.


34. Особо интересный residual regime

Не определять его вручную.

Предварительно зафиксировать ranking:

    high cross-block recurrence
    + high cross-metadata recurrence
    + high stability
    + high separation

Все компоненты хранить отдельно.

Composite score допустим только как descriptive ranking.


============================================================
PART C — RESIDUAL BOUNDARIES
============================================================


35. Conditional change points

Внутри каждого sufficiently long Currier×hand block искать change points
тем же методом, который использовался global-regime-analyze.

Не разрешать boundary detector пересекать metadata transitions.


36. Stable residual boundaries

Искать multi-scale support только внутри controlled blocks.

Создать:

    conditional_stable_boundaries.tsv


37. Boundary recurrence

Поскольку абсолютные позиции разных blocks несопоставимы, сравнивать:

- local feature change signature;
- before/after distributional profiles;
- direction of change.

Искать повторяющиеся TYPES переходов, а не одинаковые absolute positions.


38. Transition types

Для residual regimes построить transition matrix:

    R_i -> R_j

Проверить:

- повторяемость transitions;
- directionality;
- enrichment относительно shuffled controls.

PART D — STATISTICAL CONTROLS
============================================================


39. Основная null hypothesis

H0:

После conditioning на Currier×hand remaining distributional variation
не содержит reproducible structured regimes сверх ожидаемых от:

- finite sample;
- unigram composition;
- contiguous autocorrelation.


40. Не использовать random-token split

Все validation folds должны быть:

    contiguous
или
    physical-block based.

Random window split запрещён.


41. Multiple comparisons

Для Part B заранее search space:

    5 scales × K 2..15

для primary k_medoids.

Использовать max-statistic permutation correction:

    max stability/separation statistic
    over scale × K

Не выбирать красивый K постфактум.


42. Hierarchical secondary

Hierarchical анализировать отдельно.

Не объединять k_medoids и hierarchical в один search space primary test.


43. Effect size

Не ограничиваться p-values.

Всегда сохранять:

- observed statistic;
- null mean;
- null SD;
- P95;
- P99;
- null max;
- standardized effect size;
- empirical p.

============================================================
PART F — INTERPRETATION
============================================================


49. Outcome A — structure disappears

Если после conditioning:

- clustering не превосходит null;
- stability низкая;
- cross-block recurrence отсутствует;

вывод:

    previous blind distributional structure is largely explainable
    by Currier/hand heterogeneity.

Это важный отрицательный результат.


50. Outcome B — weak residual structure

Если отдельные regimes появляются, но:

- scale stability слабая;
- recurrence ограничена одним block;
- significance marginal;

вывод:

    evidence for additional organization is weak/inconclusive.


51. Outcome C — reproducible residual structure

Если после conditioning обнаруживаются regimes, которые:

- significant against controls;
- stable across scales;
- recur in multiple physical blocks;
- recur across multiple Currier/hand classes;
- have low residual association with metadata;

вывод:

    corpus contains reproducible distributional organization
    not explained by tested Currier/hand metadata.


52. Не интерпретировать семантически

Даже Outcome C НЕ означает:

- instructions;
- operators;
- operands;
- grammar;
- recipes;
- cipher;
- natural language.

Он означает только:

    additional reproducible distributional structure exists.


53. Главное ограничение

Currier и Davis hand являются metadata models, а не полной причиной
distributional heterogeneity.

"Residual after Currier×hand" означает:

    unexplained by these annotations

а не:

    independent of scribal/material effects in general.


54. Reproducibility

Все random operations deterministic.

Записать в report:

- corpus SHA256;
- token count;
- metadata-map hash;
- parameters;
- seed;
- eligible joint classes;
- excluded token count.


55. Tests

Добавить unit tests минимум для:

- joint Currier×hand class construction;
- unknown metadata exclusion;
- contiguous block extraction;
- windows never crossing metadata boundaries;
- eligibility thresholds;
- training-only residual centering;
- no held-out leakage;
- within-block token shuffle;
- window-order shuffle;
- cross-block recurrence;
- residual metadata entropy;
- max-over-scale×K permutation correction;
- deterministic seed.

Главная цель

Мы уже установили, что blind distributional regimes статистически связаны
с Currier и Davis hands.

Теперь необходимо задать более строгий вопрос:

    После того как известная Currier/hand heterogeneity
    контролируется экспериментально, остаётся ли в корпусе
    воспроизводимая структура?

Именно наличие такого residual уровня, а не ещё более высокая корреляция
с известными metadata, является целью этого эксперимента.
