Task63 — Token-to-Token Form Transition Process

Цель

Проверить гипотезу, возникшую из Tasks 58–62:

    структура Voynich может быть разделена как минимум на два уровня:

        G — локальный механизм образования допустимых token forms;
        S — механизм перехода между формами соседних tokens.

Task62 показал, что локальная position-aware Markov model способна
частично воспроизводить:

    - low glyph conditional entropy;
    - positional specialization;
    - giant d=1 vocabulary component;

но существенно недовоспроизводит:

    adjacent near-repeat enrichment.

Основной вопрос Task63:

    существует ли статистически воспроизводимый локальный
    token-to-token transformation process, который действует
    преимущественно над ФОРМОЙ предыдущего token, а не над его
    identity?

И если существует:

    достаточно ли простой модели этого процесса вместе с frozen
    Task62 token-formation model для воспроизведения наблюдаемой
    структуры Voynich?

НЕ делать выводов о языке, морфологии, шифре или дешифровке.

НЕ добавлять Stage29.
НЕ изменять Stages 1–28.
НЕ оптимизировать модель по Task58–62 fingerprint metrics.

======================================================================
1. CORE HYPOTHESIS
======================================================================

Проверить различие:

    TOKEN IDENTITY DEPENDENCE

и:

    TOKEN FORM DEPENDENCE.

Task58 показывает слабую глобальную зависимость token identities.

Task60 показывает сильное adjacent d=1 enrichment.

Task62 показывает, что independent token generation создаёт
Voynich-like vocabulary geometry, но недостаточную adjacency:

    Voynich TEST near-repeat ≈ 0.03952
    POSITION_MARKOV_1 ≈ 0.02341.

Рабочая гипотеза:

    P(T_i | T_i-1)

может быть слабой на уровне exact token identity,

но:

    P(form(T_i) | form(T_i-1))

может быть существенно структурирована.

Только после discovery/freeze разрешается generative modeling.
