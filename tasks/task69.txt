Task69 — Focused Literature Search:
Generative Replicability, Formal Grammar, and Plaintext-Fingerprint Dependence

Цель

Провести углублённый поиск литературы по трём конкретным направлениям,
выделенным после Tasks66–68.

Task69 НЕ повторяет общий literature audit Task68.

Он должен ответить на три узких вопроса:

G:
    Пытался ли кто-либо построить message-free generator,
    который многократно производит разные Voynich-like corpora
    с устойчивым многомерным fingerprint?

L:
    Пытался ли кто-либо вывести из Voynich text внутреннюю
    формальную lexical/morphological/grammatical system
    без предварительного предположения о конкретном языке?

C:
    Исследовал ли кто-либо зависимость Voynich-like ciphertext
    fingerprint от statistical/structural properties plaintext?

4. TRACK G — REPLICATION QUESTION
======================================================================

Особенно искать:

    multiple independent generated corpora;
    multiple random seeds;
    replicate distributions;
    variance across generated samples;
    frozen generator;
    held-out metrics;
    out-of-sample fingerprint;
    blind discrimination synthetic vs Voynich.

Главный вопрос:

    Был ли когда-либо проведён эксперимент:

        freeze G(theta)

        generate X1 ... XN using different seeds

        verify Fingerprint(Xi) ≈ Fingerprint(V)

    на широком наборе независимых метрик?

Классификация:

    DIRECT_PRECEDENT
    PARTIAL_PRECEDENT
    NO_DIRECT_PRECEDENT_FOUND.

21. TRACK C — CORE FUNCTION
======================================================================

Нас интересует экспериментальная функция:

    F(P,E) = fingerprint(E(P)).

И особенно:

    ΔF_ciphertext / ΔF_plaintext.

Для каждой работы определить,
какие ciphertext properties сохраняют dependence on source:

    entropy;
    n-grams;
    repetition;
    token length;
    vocabulary growth;
    local similarity;
    positional structure;
    long-range dependence.

======================================================================
22. TRACK C — SAME ENCODER, DIFFERENT PLAINTEXT
======================================================================

    E(P2)
    ...
    E(Pn)

Именно они позволяют отделить:

    encoder fingerprint

от:

    plaintext fingerprint.

Отмечать как:

    DIRECT_PLAINTEXT_SENSITIVITY_TEST.

======================================================================
24. TRACK C — CONTEXT-COMPLETION PLAINTEXT
======================================================================

Отдельно искать исторические и современные системы,
где передаётся не полное сообщение,
а только дополнение к shared context.

Термины:

    elliptical messages
    telegraphic codes
    codebooks
    shorthand
    abbreviated technical notation
    procedural codes
    military brevity codes
    commercial codes
    nomenclators
    shared-context communication.

Цель — понять статистические свойства source text,
а не доказать историческую связь с Voynich.

======================================================================
25. TRACK C — LOW-INFORMATION PLAINTEXT
======================================================================

Особенно интересен случай:

    M = K + ΔI

где:

    K = shared prior/context
    ΔI = transmitted information.

Искать литературу по communication with side information,
source coding with shared context и historical code systems.

Отделять mathematical analogy от historical evidence.

======================================================================
26. TRACK C — INFORMATION RATE
======================================================================

Для таких systems искать:

    information per symbol;
    redundancy;
    source entropy;
    conditional entropy H(M|K);
    compressed/abbreviated message structure.

Это поможет определить,
может ли meaningful plaintext иметь
необычно низкую source complexity до encryption.

======================================================================

34. MOST IMPORTANT QUESTION FOR L
======================================================================

        объясняет word formation;
        выявляет productive lexical paradigms;
        предсказывает held-out forms;
        описывает sequence grammar;
        проверена против generator controls?

    Voynich-like cipher fingerprint к классу plaintext,
    особенно к non-prose / compressed / contextual /
    procedural source messages?

40. DEFINITION OF DONE
======================================================================

Task69 завершён, когда:

1. выполнен новый focused search по G/L/C;

2. Task68 citation graph расширен;

3. Timm/Schinner разобраны на уровне generator mechanics;

4. найдены или не найдены multi-seed replication studies;

5. generator metric coverage построен;

6. проведён отдельный поиск Voynich morphology/grammar;

7. lexical-family/paradigm literature разобрана;

8. formal grammar attempts разобраны;

9. held-out productivity tests специально искались;

10. generator alternatives для language models проверены;

11. выполнен поиск plaintext-dependence literature;

12. same-encoder/different-plaintext studies найдены или
    документировано их отсутствие;

13. non-prose plaintext classes исследованы;

14. context-completion/shared-knowledge communication рассмотрено;

15. Greshko/Bowern-Gaskell переоценены с точки зрения
    plaintext sensitivity;

16. general mechanistic literature использована там,
    где Voynich literature отсутствует;

17. direct/partial/no-precedent verdict дан для G/L/C;

18. составлен experiment crosswalk;

19. рекомендовано следующее экспериментальное направление;

20. отсутствие найденной работы нигде не выдано
    за доказательство её несуществования.
