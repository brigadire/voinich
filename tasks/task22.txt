Задача: higher-order-sequence-validate

Цель

Проверить, существует ли в canonical corpus воспроизводимая
последовательностная зависимость порядка >=2, которую нельзя объяснить:

    unigram frequencies
    pairwise/bigram transitions
    Currier class
    Davis hand
    physical block

Основной вопрос:

Для наблюдаемой последовательности

    A B C

содержит ли A дополнительную информацию о C после того,
как B уже известен?

Формально проверить:

    P(C | A,B)

против:

    P(C | B)

и:

    I(A ; C | B)

Если зависимость сохраняется между независимыми physical blocks,
это является свидетельством higher-order sequential constraint.

Это НЕ означает автоматически:

    natural language
    grammar
    operator
    operand
    instruction
    cipher
    semantics.

PART B — CONDITIONAL PROBABILITIES

10. Primary effect:

    conditional_enrichment =
        P(C | A,B) / P(C | B)


11. Также считать:

    delta_probability =
        P(C | A,B) - P(C | B)


12. Не использовать effect, если denominator недостаточен.

Primary block eligibility:

    count(AB) >= 3
    count(B) >= 10

Дополнительно descriptive:

    count(AB) >= 2

Но не смешивать эти уровни.

================================================================
PART C — REVERSE CONDITIONAL TEST
================================================================

14. Проверить симметричный вопрос:

Для ABC несёт ли C информацию об A после B?

Считать:

    P(A | B,C)

против:

    P(A | B)


15. Это важно для определения направленности constraint.

Считать:

    reverse_enrichment
    reverse_delta_probability


16. Не считать forward/reverse отдельными discoveries.
Это две заранее определённые характеристики одной frozen relation.


================================================================
PART D — CONDITIONAL MUTUAL INFORMATION
================================================================

17. Primary information-theoretic statistic:

    I(A ; C | B)

Но здесь A и C нельзя трактовать просто как две бинарные константы.

Для каждого central token B построить distribution:

    left neighbor X
    right neighbor Y

и оценить:

    I(X ; Y | center=B)


18. Затем отдельно измерить contribution конкретной frozen ABC
к зависимости вокруг B.


19. Обязательно применить finite-sample bias control.

Primary:

    permutation-based null

Не полагаться только на plug-in CMI estimator.


20. Permutation null:

внутри каждого physical block и для каждого B
переставлять правых соседей между occurrences B.

Это сохраняет:

    count(B)
    left-neighbor distribution around B
    right-neighbor distribution around B
    block composition

и разрушает:

    dependence left <-> right conditional on B.


21. Не переставлять данные между physical blocks.


================================================================
PART E — LOG-LIKELIHOOD / MODEL COMPARISON
================================================================

22. Сравнить две модели.


M1 — first order:

    P(C | B)


M2 — second order:

    P(C | A,B)


23. Оценивать predictive performance на held-out physical blocks.

Никакого random occurrence split.


24. Leave-one-physical-block-out:

training:

    все eligible blocks кроме одного

test:

    held-out block


25. На training оценить transition probabilities.


26. Использовать фиксированное smoothing:

    additive alpha = 0.5

Не оптимизировать alpha.


27. Для held-out observations вычислить:

    log_loss_M1
    log_loss_M2

    delta_log_loss =
        log_loss_M1 - log_loss_M2

Положительное значение означает преимущество second-order model.


28. Также:

    heldout_log_likelihood_ratio


29. Для каждого sequence вывести:

    tested_blocks
    M2_better_blocks
    M1_better_blocks
    ties

    mean_delta_log_loss
    median_delta_log_loss


================================================================
PART F — CONTEXT SUBSTITUTION CONTROLS
================================================================

30. Для frozen ABC проверить альтернативные contexts.


Для:

    A B C

сравнить:

    A B C

с:

    X B C

где X != A.


31. И:

    A B X

где X != C.


32. Не выбирать X по максимальному/минимальному effect.

Использовать ВСЕ sufficiently frequent alternatives.


33. Для каждого B построить таблицу:

    left token
    right token
    count


34. Определить:

является ли C особенно характерным продолжением именно после AB,
или C является обычным частым continuation самого B.


================================================================
PART G — CONDITIONAL CONTINUATION DISTRIBUTION
================================================================

35. Для каждого frozen AB построить:

    P(X | A,B)

по всем возможным X.


36. Для B построить:

    P(X | B)


37. Сравнить distributions:

    JS divergence
    total variation distance


38. Важно:

если:

    P(X | A,B)

существенно отличается от:

    P(X | B)

то A влияет не только на один frozen C,
а на весь набор продолжений B.


39. Вывести:

    entropy H(X | B)
    entropy H(X | A,B)


40. Рассчитать:

    entropy_reduction =
        H(X | B) - H(X | A,B)


41. Положительная entropy reduction означает,
что знание A делает continuation после B более предсказуемым.

================================================================
PART P — OUTCOME CLASSIFICATION
================================================================

78. Для каждой primary sequence присвоить один diagnostic status.


HIGHER_ORDER_REPLICATED

если:

    conditional-dependence FDR q <= 0.05
    eligible physical blocks >= 3
    sign consistency >= 0.75
    LOBO M2 better than M1 in >= 2/3 tested blocks
    jackknife does not collapse
    evidence spans >=2 joint metadata classes


FIRST_ORDER_EXPLAINED

если:

    second-order predictive model does not improve held-out prediction
или
    conditional permutation test non-significant


POSITION_DEPENDENT

если higher-order effect существенно локализован
на block/line boundaries


METADATA_LIMITED

если effect воспроизводится,
но только внутри одного Currier/hand/joint class


SINGLE_BLOCK_SENSITIVE

если effect исчезает после удаления одного physical block


INSUFFICIENT_SUPPORT

если невозможно получить >=3 eligible blocks.

================================================================
ГЛАВНЫЙ ИССЛЕДОВАТЕЛЬСКИЙ ВОПРОС
================================================================

Предыдущий audit установил, что существуют frozen триграммы,
межблочная recurrence которых превышает frequency-aware null,
а для части из них — также first-order Markov expectation.

Теперь нужно проверить более сильное утверждение:

    влияет ли первый элемент последовательности
    на выбор третьего элемента
    при фиксированном втором?

То есть:

             A
             |
             v
        B -> C

против first-order модели:

        B -> C


Если:

    P(C | A,B) != P(C | B)

и эта зависимость:

    significant against conditional null
    reproduces across independent physical blocks
    survives leave-one-block-out
    improves held-out prediction over P(C|B)
    survives jackknife

то мы получаем evidence не просто повторяемой последовательности,
а воспроизводимого higher-order sequential constraint.

Это следующий уровень проверки гипотезы о наличии
формальной системы локальных правил.
