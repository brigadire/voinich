Задача: transition-network-validate

Цель

Проверить, существует ли в canonical corpus устойчивая направленная сеть
локальных переходов между токенами, воспроизводимая между независимыми:

    physical blocks
    Currier classes
    Davis hands
    joint Currier×hand classes

и не объясняемая только:

    глобальными частотами токенов
    block-specific vocabulary
    общей неоднородностью корпуса
    единичными высокочастотными биграммами.

Главный вопрос:

    Существует ли воспроизводимая топология предпочтительных
    и подавленных переходов A -> B?

То есть интересует не отдельная редкая конструкция A B C,
а структура множества допустимых/предпочтительных переходов:

    A -> {B,C,D,...}

и, возможно:

    A -/> {E,F,G,...}

если эта структура воспроизводится между независимыми частями корпуса.

================================================================
2. НИКАКОГО НЕОГРАНИЧЕННОГО DISCOVERY
================================================================

Не искать новые токены.

Но полный набор реально наблюдавшихся adjacent transitions canonical corpus
является естественным объектом этой задачи и может быть построен заново.

Это не candidate mining в прежнем смысле:
каждое наблюдавшееся A -> B является элементом одной заранее определённой
transition matrix.

Нельзя постфактум подбирать:

    distance
    smoothing
    thresholds
    graph metric
    minimum count

для получения более красивого результата.


================================================================
3. PRIMARY RELATION
================================================================

Основная сеть:

    adjacent transition A -> B

то есть exact distance +1.

Не использовать ±2..±20 в primary analysis.

Причина:

нужно начать с минимальной локальной relation,
которая имеет максимально ясную статистическую интерпретацию.


4. Secondary descriptive network:

    distance +2

можно сохранить только как diagnostic,
но не использовать для primary inference.


================================================================
4. PHYSICAL BLOCKS
================================================================

Использовать те же physical blocks, что в residual diagnostics:

    contiguous run одного known Currier×hand state.

Unknown metadata regions:

    исключить из PRIMARY cross-block evidence.

Их transitions можно сохранить отдельно descriptive.


5. Никакой transition не должна пересекать physical-block boundary.


================================================================
5. TOKEN ELIGIBILITY
================================================================

Primary token eligibility:

    global count >= 10

Secondary diagnostic:

    global count >= 5

Не менять thresholds после просмотра результатов.


6. Primary block-level transition eligibility:

для source token A в block:

    count(A in block) >= 5

Для конкретного edge A -> B:

    observed opportunity count >= 5

где opportunity count =
    число A, имеющих следующий token внутри того же block.


================================================================
PART A — BLOCK-NORMALIZED TRANSITION EFFECT
================================================================

7. Для каждого block и каждого A -> B считать:

    count(A)
    count(B)
    count(A -> B)

    P(B | A, block)

и baseline:

    P(B | block)


8. Primary edge enrichment:

    enrichment(A->B, block) =
        P(B | A, block)
        /
        P(B | block)


9. Также считать:

    log2_enrichment =
        log2(enrichment)


10. При нулевых counts использовать фиксированное smoothing:

    additive alpha = 0.5

Не оптимизировать alpha.


11. Сохранять raw unsmoothed counts рядом.


================================================================
PART B — DEPLETED TRANSITIONS
================================================================

12. Анализировать не только enrichment > 1.

Для каждого edge определить:

    preferred:
        enrichment > 1

    depleted:
        enrichment < 1


13. Особый интерес:

устойчиво подавленные переходы.

Если A и B оба часты,
но A -> B систематически встречается реже baseline в разных blocks,
это потенциально сильное ограничение.


14. Не называть такие edges "forbidden".

Использовать:

    reproducibly depleted transition.


================================================================
PART C — CROSS-BLOCK EDGE REPLICATION
================================================================

15. Для каждого globally observed edge собрать block-level effects.

Вывести:

    eligible_blocks
    positive_blocks
    negative_blocks
    neutral_blocks

    sign_consistency

    median_log2_enrichment
    mean_log2_enrichment
    between_block_sd


16. Primary replicated edge criterion:

    eligible_blocks >= 3

и:

    same enrichment sign in >=75% eligible blocks

и:

    evidence spans >=2 joint metadata classes.


17. Отдельно сохранять:

    Currier classes
    hands
    joint classes
    physical blocks


================================================================
PART D — LEAVE-ONE-BLOCK-OUT EDGE TRANSFER
================================================================

18. Для каждого candidate replicated edge:

training:

    all eligible blocks except one

определить expected sign:

    preferred / depleted


19. На held-out block проверить sign.


20. Вывести:

    tested_blocks
    successful_sign_predictions
    transfer_fraction


21. Edge считается transferable, если:

    transfer_fraction >= 0.67


================================================================
PART E — FREQUENCY-MATCHED NULL
================================================================

22. Для каждого edge A -> B нужен null,
который учитывает частоты A и B.

Primary null:

    within-block destination permutation conditional on source opportunities.


23. В каждом physical block:

сохранять sequence source positions A,
но переставлять destination tokens между transition opportunities
внутри block.

Это сохраняет:

    block unigram composition
    transition opportunity count
    source frequencies
    destination frequencies

и разрушает:

    A-specific destination association.


24. Нельзя permute между blocks.


25. Primary permutations:

    1000


26. Refinement:

    10000

только если заранее:

    raw p < 0.01
    eligible_blocks >=3
    joint classes >=2


27. empirical p:

    (exceedances + 1)/(N + 1)


================================================================
PART F — MULTIPLE COMPARISONS
================================================================

28. Поскольку edges много, применить:

    BH FDR q=0.05

отдельно для:

    preferred edges
    depleted edges


29. Не выбирать только strongest raw p без FDR.


================================================================
PART G — NODE-LEVEL TRANSITION PROFILE
================================================================

30. Для каждого source token A построить block-level outgoing profile:

    P(B | A, block)

по всем B.


31. Сравнивать outgoing profiles A между blocks.


32. Для каждого A считать:

    pairwise JS similarity between eligible block profiles

    mean
    median
    minimum
    SD


33. Leave-one-block-out:

reference outgoing profile =
    aggregate from all other eligible blocks

held-out similarity =
    similarity(block profile, reference)


34. Это PRIMARY node-level question:

    воспроизводится ли множество продолжений A,
    а не только отдельное edge?


================================================================
PART H — LOCAL BASELINE NORMALIZATION
================================================================

35. Дополнительно построить normalized outgoing effect profile:

для каждого destination B:

    E_A(B,block) =
        log2[
          P(B | A,block)
          /
          P(B | block)
        ]


36. Это важнее raw P(B|A),
потому что удаляет block vocabulary-frequency effect.


37. Сравнивать именно E_A vectors между blocks:

    cosine similarity
    Pearson/Spearman
    sign agreement


38. Основная metric:

    sign agreement + correlation

Не использовать только cosine.


================================================================
PART I — NODE PROFILE REPLICATION
================================================================

39. Token A считается replicated transition-profile token, если:

    eligible blocks >=3
    joint classes >=2

и:

    median LOBO normalized-profile correlation > 0

и:

    profile similarity significant against block-permutation null

и:

    sign pattern reproducible above null.


40. Не использовать arbitrary high correlation threshold
кроме заранее фиксированного >0 для direction
и inferential null.


================================================================
PART J — OUTGOING ENTROPY
================================================================

41. Для каждого A и block считать:

    H(next | A, block)

    effective successor count = exp(H)


42. Сравнить с block baseline successor entropy.


43. Определить tokens с reproducibly:

    restricted continuation set

или:

    broad continuation set.


44. Cross-block criterion тот же:

    >=3 blocks
    >=2 joint classes
    sign consistency >=0.75


45. Frequency-matched controls обязательны.


================================================================
PART K — INCOMING PROFILE
================================================================

46. Симметрично построить incoming network:

    P(A | previous token, block)

или, удобнее для token B:

    distribution of predecessors of B.


47. Для каждого token хранить отдельно:

    outgoing profile stability
    incoming profile stability


48. Это позволит различать tokens,
которые устойчивы как:

    source-like
    sink-like
    bidirectionally constrained


49. Это чисто structural labels,
не semantic roles.


================================================================
PART L — NETWORK TOPOLOGY
================================================================

50. После edge validation построить graph только из:

    FDR-significant replicated preferred/depleted edges.


51. Два графа:

    preferred graph
    depleted graph


52. Не смешивать их.


53. Для preferred graph считать:

    in-degree
    out-degree
    weighted in-degree
    weighted out-degree

    strongly connected components
    weakly connected components

    reciprocity

    assortativity, если легко


54. Weighted edge weight:

    median block log2 enrichment

55. Не использовать PageRank как primary result.

PART Z — INTERPRETATION
================================================================

106. Возможные outcomes:


A. NO BACKBONE

Few/no edges survive FDR + cross-block transfer.

Вывод:

    local transition structure is mostly block/metadata specific.


B. EDGE BACKBONE ONLY

Stable preferred/depleted edges exist,
but node profiles/prediction weak.

Вывод:

    limited transferable pairwise constraints exist.


C. PROFILE BACKBONE

Whole successor/predecessor profiles reproduce,
and M1 improves held-out prediction.

Вывод:

    corpus contains a transferable first-order transition system.


D. HIGHER ORDER NEEDED

First-order backbone reproduces,
but M2 significantly improves held-out prediction across blocks.

Вывод:

    transferable local structure exists beyond first-order transitions.

================================================================
ГЛАВНАЯ ЦЕЛЬ
================================================================

Предыдущие эксперименты показали, что поиск отдельных редких
higher-order sequences быстро упирается в малое число наблюдений
и плохую cross-block replication.

Теперь проверяется более фундаментальная гипотеза:

    у каждого token A существует не случайный набор возможных
    продолжений, а воспроизводимый transition profile,

причём этот профиль сохраняется после локальной нормализации
на частоты tokens внутри physical block.

Если существует устойчивый network backbone из preferred
и depleted transitions, воспроизводимый между Currier classes,
hands и independent physical blocks, это будет более сильным
свидетельством формальной локальной организации корпуса,
чем единичные повторяющиеся n-grams.

Особенно важны два результата:

1. transferable normalized successor profiles;

2. held-out prediction:
       P(next | current)
   лучше
       P(next | block).

Только если оба эффекта присутствуют, имеет смысл дальше
исследовать transition network как возможную основу системы правил.
