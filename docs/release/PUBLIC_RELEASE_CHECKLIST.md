# Public release checklist

- [x] Security audit documented
- [x] Privacy audit documented
- [ ] Corpus licensing resolved
- [ ] Third-party licensing resolved
- [ ] Project license selected
- [x] README prepared
- [x] DATA prepared
- [x] REPRODUCIBILITY prepared
- [x] CITATION prepared
- [x] Clean build and tests completed
- [x] Artifact links reviewed
- [ ] Release blockers resolved
- [ ] Human owner review completed
- [ ] Repository visibility changed manually, if desired

The final item is intentionally manual. Do not change repository visibility or
push a public release without the owner's separate approval.
