# Project license options

No project license is present in the repository. This is a maintainer decision,
not an inference from the research, and until it is made the code,
documentation, and generated artifacts are not offered under a public license.

| Option | Source code | Documentation and generated research artifacts |
| --- | --- | --- |
| Apache-2.0 | Permissive use with explicit patent grant and notice retention | Can be separately CC BY 4.0, but this does not clear third-party corpora or IVTT. |
| MIT | Short permissive notice; no explicit patent grant | Can be separately CC BY 4.0; attribution expectations are clear but corpus rights remain separate. |
| GPL-3.0-or-later | Copyleft for distributed derivative software | Documentation/artifacts need a separate license such as CC BY 4.0; assess compatibility with downstream research tooling. |

A selected license must name its scope explicitly. It must not purport to
license corpus bytes, the IVTT tool, or any other material whose rights remain
unclear.
